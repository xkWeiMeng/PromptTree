## Where Are Your Prompts?

Ask someone who uses ChatGPT daily this question, and you'll likely get an awkward smile.

The more frequently you use AI tools, the worse the Prompt management chaos becomes. This isn't the user's fault — it's a gap in the entire toolchain.

## Five Pain Points

### 1. Scattered Everywhere

Research shows that most users' Prompts are scattered across at least 3 different places — note-taking apps, browser bookmarks, chat histories, even messaging apps' "Saved Messages."

There's no consensus on "this is where Prompts should go," because no tool was purpose-built for it.

### 2. Can't Find Them

"I remember writing a really great translation Prompt before, but I can't find it."

This is the most common complaint. When your Prompts are scattered and uncategorized, both recall and search become difficult.

### 3. Can't Reuse Them

Good Prompts are often template-like. For example, translation — the core structure is fixed, you only need to swap the source language, target language, and content. But in most note-taking tools, you have to manually edit each time.

### 4. No Cross-Device Access

Prompts organized on your computer can't be used on your phone. Bookmarks saved in Chrome disappear when you switch browsers.

### 5. Network Dependent

Many management tools rely on the cloud. Want to look up a Prompt on the subway or a plane? Sorry, no network, no access.

## Our Approach

For these pain points, PromptTree's solutions are:

| Pain Point | Solution |
|------------|----------|
| Scattered everywhere | A unified tree-structured Prompt library |
| Can't find them | Categorization + Search + Favorites |
| Can't reuse them | `{{variable}}` variable filling |
| No cross-device access | Web + App + Extension + Cloud sync |
| Network dependent | Offline-first architecture |

Every design decision stems from real usage pain points. We believe good tools should solve real problems, not create new complexity.

## From Pain Points to Product

Understanding these pain points is only the first step. The real challenge is: how do you solve all these problems in a simple product without making it complicated?

PromptTree's answer: return to the most fundamental interaction — the file manager. Everyone knows how to use folders and files — no new concepts to learn.

On top of that foundation, add capabilities specific to the Prompt use case (variable filling, one-click copy, browser extension insertion), making the tool both simple and powerful.
