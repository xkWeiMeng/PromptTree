## あなたのプロンプトはどこにありますか？

毎日 ChatGPT を使っている人にこの質問をすると、おそらく困ったような笑みが返ってくるでしょう。

AI ツールの使用頻度が高まるほど、プロンプト管理の混乱は深刻になります。これはユーザーの問題ではなく、ツールチェーン全体の欠如です。

## 5つの課題

### 1. あちこちに散在

調査の結果、ほとんどのユーザーのプロンプトは少なくとも3つの異なる場所に散らばっていることがわかりました——ノートアプリ、ブラウザのブックマーク、チャット履歴、さらには LINE の「Keep メモ」まで。

「プロンプトはここに置くべき」というコンセンサスがないのは、そのために生まれたツールがないからです。

### 2. 見つからない

「以前書いたすごく便利な翻訳プロンプトがあったはずなのに、見つからない。」

これが最もよくある不満です。プロンプトがあちこちに分散して分類もされていないと、思い出すことも検索することも困難になります。

### 3. 再利用できない

優れたプロンプトはテンプレート化されていることが多いです。例えば翻訳なら、コアの構造は固定で、原言語、目標言語、内容を置き換えるだけです。しかしほとんどのノートツールでは、毎回手動で修正する必要があります。

### 4. デバイス間で共有できない

パソコンで整理したプロンプトがスマートフォンでは使えない。Chrome のブックマークに保存したものは、別のブラウザに切り替えるとなくなってしまう。

### 5. ネットワーク依存

多くの管理ツールはクラウドに依存しています。電車の中や飛行機の中でプロンプトを確認したい？申し訳ありませんが、ネットがなければ使えません。

## 解決アプローチ

これらの課題に対する PromptTree の解決策は以下の通りです：

| 課題 | 解決策 |
|------|--------|
| あちこちに散在 | 統一されたツリー型プロンプトライブラリ |
| 見つからない | 分類 + 検索 + お気に入り |
| 再利用できない | `{{variable}}` 変数埋め込み |
| デバイス間で共有できない | Web + アプリ + 拡張機能 + クラウド同期 |
| ネットワーク依存 | オフラインファーストアーキテクチャ |

すべての設計判断は、実際の使用上の課題から生まれています。良いツールは実際の問題を解決すべきであり、新たな複雑さを生み出すべきではないと私たちは信じています。

## 課題からプロダクトへ

これらの課題を理解することは第一歩に過ぎません。本当のチャレンジは、シンプルなプロダクトの中でこれらすべての問題を同時に解決しつつ、プロダクトを複雑にしないことです。

PromptTree の答えは、最も基本的なインタラクションに立ち返ることです——ファイルマネージャー。誰もがフォルダとファイルの使い方を知っており、新しい概念を学ぶ必要はありません。

その上に、プロンプト特有の機能（変数埋め込み、ワンクリックコピー、ブラウザ拡張機能での入力）を加えることで、シンプルでありながら強力なツールを実現しています。
