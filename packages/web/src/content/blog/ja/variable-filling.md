## あるシナリオ

あなたが翻訳者で、毎日 AI を使ってさまざまな言語のテキストを翻訳する必要があるとしましょう。プロンプトはだいたいこんな感じです：

```
以下の中国語テキストを英語に翻訳してください。原文のトーンを維持してください。専門用語の正確さに注意してください。

原文：
（ここに中国語の内容を貼り付け）
```

問題は、中国語から英語への翻訳だけではないということです。こんな翻訳も必要かもしれません：
- 中国語 → 英語
- 英語 → 中国語
- 日本語 → 中国語
- 中国語 → フランス語

毎回手動で言語ペアを変更するのは面倒です。似ているがパラメータが異なるプロンプトが10個あれば、10個のバージョンを管理しなければなりません。

## 変数埋め込みによる解決

PromptTree では、**たった1つ**のプロンプトテンプレートで済みます：

```
以下の {{原言語}} テキストを {{目標言語}} に翻訳してください。原文のトーンを維持してください。
{{分野}} 分野の専門用語の正確さに注意してください。

原文：
{{翻訳対象の内容}}
```

1つのテンプレートですべての翻訳シナリオをカバーできます。

## 使い方の流れ

1. コピーボタンをクリック
2. PromptTree が自動的に4つの変数を検出
3. 埋め込みウィンドウがポップアップし、各変数に入力欄が表示される
4. 入力：原言語=中国語、目標言語=英語、分野=医学、翻訳対象の内容=...
5. 「コピー」をクリック——変数が置換され、完成したプロンプトがクリップボードにコピーされる

全工程10秒以内。

## 設計哲学

変数埋め込みの設計は1つの原則に従っています：**最小限の手間で再利用。**

プログラミングを学ぶ必要も、テンプレートエンジンを理解する必要もありません。2つの波括弧で名前を囲めば、それが変数です。コピーをクリックすればポップアップで入力でき、入力が完了すれば結果が得られます。

これにより、プロンプトは「使い捨てのテキスト」から「再利用可能なテンプレート」に変わり、あなたのプロンプトライブラリは真の複利効果を生み出し始めます。
