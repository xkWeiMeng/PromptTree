## 여러분의 프롬프트는 어디에 있나요?

매일 ChatGPT를 사용하는 사람에게 이 질문을 하면, 대부분 멋쩍은 웃음을 짓게 될 것입니다.

AI 도구의 사용 빈도가 높아질수록 프롬프트 관리의 혼란은 더 심해집니다. 이것은 사용자의 문제가 아니라, 전체 도구 생태계의 부재입니다.

## 다섯 가지 문제점

### 1. 여기저기 흩어져 있음

조사 결과, 대부분의 사용자는 프롬프트가 최소 3곳 이상에 흩어져 있습니다 — 노트 앱, 브라우저 북마크, 채팅 기록, 심지어 메신저의 '나에게 보내기' 기능까지.

'프롬프트는 여기에 저장해야 한다'라는 공감대가 없습니다. 이를 위해 만들어진 도구가 없기 때문입니다.

### 2. 찾을 수 없음

"예전에 정말 잘 만든 번역 프롬프트가 있었는데, 찾을 수가 없어요."

가장 흔한 불만입니다. 프롬프트가 여기저기 흩어져 있고 분류가 되어 있지 않으면, 기억해 내는 것도 검색하는 것도 어려워집니다.

### 3. 재사용 불가

좋은 프롬프트는 대개 템플릿화가 가능합니다. 예를 들어 번역의 경우, 핵심 구조는 동일하고 원본 언어, 대상 언어, 내용만 바꾸면 됩니다. 하지만 대부분의 노트 도구에서는 매번 수동으로 수정해야 합니다.

### 4. 디바이스 간 연결 부재

컴퓨터에서 정리한 프롬프트를 스마트폰에서는 사용할 수 없습니다. Chrome 북마크에 저장한 것은 다른 브라우저로 바꾸면 사라집니다.

### 5. 네트워크 의존

많은 관리 도구가 클라우드에 의존합니다. 지하철에서, 비행기에서 프롬프트를 확인하고 싶으신가요? 네트워크가 없으면 사용할 수 없습니다.

## 해결 방안

이러한 문제점에 대해 PromptTree의 해결책은 다음과 같습니다:

| 문제점 | 해결책 |
|--------|--------|
| 여기저기 흩어져 있음 | 통합된 트리 구조 프롬프트 라이브러리 |
| 찾을 수 없음 | 분류 + 검색 + 즐겨찾기 |
| 재사용 불가 | `{{variable}}` 변수 채우기 |
| 디바이스 간 연결 부재 | Web + App + 확장 프로그램 + 클라우드 동기화 |
| 네트워크 의존 | 오프라인 우선 아키텍처 |

모든 설계 결정은 실제 사용 시 느끼는 문제점에서 비롯되었습니다. 저희는 좋은 도구란 실질적인 문제를 해결해야 하며, 새로운 복잡성을 만들어서는 안 된다고 믿습니다.

## 문제점에서 제품으로

이러한 문제점을 파악하는 것은 첫 번째 단계에 불과합니다. 진정한 도전은 간결한 하나의 제품에서 이 모든 문제를 동시에 해결하면서도 제품을 복잡하게 만들지 않는 것입니다.

PromptTree의 답은 가장 기본적인 인터랙션으로 돌아가는 것입니다 — 파일 관리자. 누구나 폴더와 파일 사용법을 알고 있으므로, 새로운 개념을 학습할 필요가 없습니다.

이 기반 위에 프롬프트 시나리오에 특화된 기능(변수 채우기, 원클릭 복사, 브라우저 확장 프로그램 입력)을 추가하여, 도구를 간단하면서도 강력하게 만들었습니다.
