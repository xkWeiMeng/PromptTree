저희는 사용자분들로부터 자주 이런 질문을 받습니다: "PromptTree가 정말 저에게 맞나요?" "이것으로 무엇을 할 수 있나요?"

기능을 일반적으로 소개하기보다, 실제 시나리오로 답하는 것이 더 낫겠다고 생각했습니다. 이 글에서는 **40개 이상의 시나리오 Q&A**를 정리하여, 콘텐츠 제작, 개발, 팀 협업, 지식 관리 등 다양한 방향을 다룹니다. AI를 처음 사용하는 초보자든, 하루에 수백 개의 프롬프트를 소비하는 헤비 유저든, 자신에게 맞는 사용 시나리오를 찾을 수 있습니다.

## 1. 입문 및 기본 조작

### Q1: 가끔 ChatGPT를 사용할 뿐인데, 프롬프트를 관리하는 전용 도구가 필요한가요?

**A:** 이미 10개 이상의 자주 쓰는 프롬프트를 모아두셨다면 한번 사용해 보실 가치가 있습니다. PromptTree는 가입이 필요 없고 열면 바로 사용할 수 있습니다 — 프롬프트는 모두 로컬 브라우저에 저장됩니다. 자주 쓰는 번역, 글쓰기, 요약 프롬프트를 저장해 두면 다음번에 원클릭으로 복사할 수 있어, 매번 다시 기억하고 입력하는 시간을 절약할 수 있습니다.

### Q2: 계정을 등록하고 싶지 않은데, 사용할 수 있나요?

**A:** 완전히 가능합니다. PromptTree는 **오프라인 우선** 아키텍처를 채택하여, 모든 데이터가 기본적으로 브라우저 로컬(IndexedDB)에 저장됩니다. 가입이나 로그인 없이 웹 페이지를 열면 바로 폴더를 만들고, 프롬프트를 작성하고, 변수 채우기를 사용할 수 있습니다. 멀티 디바이스 동기화가 필요할 때만 로그인하면 됩니다.

### Q3: 프롬프트가 점점 늘어나는데, 어떻게 정리해야 엉망이 되지 않을까요?

**A:** **트리 구조 폴더**를 사용하여 관리하세요. 컴퓨터에서 폴더로 파일을 관리하듯이 — 여러 단계의 중첩 폴더를 만들 수 있습니다. 예를 들어 '업무 / 주간보고 / 영문판', '개인 / 번역 / 한영번역'. 드래그 앤 드롭 정렬, 펼치기/접기, 이름 변경을 지원하며, 인터랙션 방식이 macOS Finder와 동일하여 학습 비용이 제로입니다.

### Q4: 특별히 자주 쓰는 프롬프트가 몇 개 있는데, 매번 한참 뒤져야 찾을 수 있습니다. 어떻게 하면 좋을까요?

**A:** 별표 **즐겨찾기**를 추가하세요. 즐겨찾기한 프롬프트는 사이드바의 '즐겨찾기' 영역에 표시되어 한 번에 접근할 수 있습니다. 또한 `⌘+K`(Mac) 또는 `Ctrl+K`(Windows)로 글로벌 검색을 실행하면, 키워드를 입력하여 즉시 찾을 수 있습니다.

### Q5: 채팅 기록에서 유용한 AI 답변도 저장하고 싶은데, 가능한가요?

**A:** 물론입니다. PromptTree에서 새 프롬프트를 만들고 답변 내용을 붙여넣기만 하면 됩니다. 'AI 우수 답변' 폴더를 만들어 다양한 주제의 좋은 답변을 분류 저장하면, 자신만의 AI 지식 베이스를 점차 구축할 수 있습니다.

## 2. 콘텐츠 크리에이터 시나리오

### Q6: 저는 소셜 미디어 운영자인데, 매일 다양한 플랫폼의 카피를 써야 합니다. 어떻게 효율을 높일 수 있나요?

**A:** '카피 템플릿' 폴더를 만들고, 플랫폼별로 하위 폴더를 나누세요(인스타그램, 블로그, 유튜브 등). 각 프롬프트에 **변수 채우기** 기능을 사용합니다: 예를 들어 `{{제품명}}에 대한 {{플랫폼}} 스타일의 홍보 카피를 작성해 주세요. 타겟 대상은 {{사용자 페르소나}}이며, 핵심 셀링 포인트는 {{셀링 포인트}}입니다`. 매번 변수 몇 개만 채우면 5초 만에 새 프롬프트가 완성됩니다.

### Q7: 한국어 콘텐츠를 여러 언어로 번역해야 하는 일이 자주 있는데, 이 과정을 간소화할 수 있나요?

**A:** 이것이 변수 채우기의 대표적인 시나리오입니다. 번역 프롬프트 하나를 만드세요: `다음 {{원본 언어}} 콘텐츠를 {{대상 언어}}로 번역해 주세요. 분야는 {{업종}}, 스타일 요구사항은 {{스타일}}입니다:\n\n{{번역할 내용}}`. 한영, 한일, 한중 번역이든, 같은 템플릿에서 변수 값만 바꾸면 됩니다.

### Q8: 장문 작성 시 단계별로 질문하는 습관이 있습니다(먼저 아웃라인, 이어서 단락, 마지막으로 퇴고). 이런 단계들을 어떻게 관리하나요?

**A:** 하나의 폴더 아래에 순서 있는 여러 프롬프트를 만드세요. 예를 들어 `01-아웃라인 생성`, `02-단락 확장`, `03-퇴고 최적화`, `04-제목 생성`. 각 프롬프트에 변수로 동적 콘텐츠를 표시하면(예: `{{글 주제}}`, `{{목표 글자 수}}`), 자신만의 '장문 생산 라인'이 완성됩니다.

### Q9: SEO 콘텐츠를 제작하고 있어서, 다양한 키워드에 대해 대량의 글을 생성해야 합니다. PromptTree가 도움이 될까요?

**A:** 네. SEO 글 템플릿을 만드세요: `키워드 "{{키워드}}"를 중심으로 {{글자 수}}자 분량의 SEO 친화적인 글을 작성해 주세요. H2/H3 제목을 포함하고, 키워드를 {{횟수}}회 자연스럽게 삽입해 주세요`. 매번 다른 키워드를 입력하고 원클릭으로 AI 도구에 복사하세요. 브라우저 확장 프로그램을 활용하면 페이지를 전환할 필요도 없습니다.

### Q10: 같은 제품에 대해 다양한 톤의 카피를 써야 합니다(공식/활기찬/전문적). 매번 많은 부분을 수정해야 하나요?

**A:** 변수에 `{{톤}}`을 하나 추가하면 됩니다. 같은 프롬프트 템플릿에서 '공식 비즈니스풍', '활기찬 소셜풍', '전문 기술풍'을 입력하면 완전히 다른 결과물을 얻을 수 있습니다. 다양한 톤의 템플릿을 각각 같은 폴더에 저장해 두어 빠르게 전환할 수도 있습니다.

### Q11: 제 프롬프트는 여러 차례 반복 개선을 거쳐 좋아진 건데, 실수로 수정하는 것을 어떻게 방지하나요?

**A:** PromptTree에서는 저장할 때마다 버전 번호가 업데이트됩니다(`version` 필드 증가). 이미 잘 다듬어진 프롬프트에 즐겨찾기 마커를 추가하고, 별도로 '실험 영역' 폴더를 만들어 새 버전을 테스트하세요. 효과가 좋다고 확인되면 정식 버전을 교체하면 됩니다.

## 3. 개발자 시나리오

### Q12: 코드 리뷰 시 AI를 자주 활용하는데, 리뷰 프롬프트를 어떻게 관리하나요?

**A:** 'Code Review' 폴더를 만들고, 언어나 관심 사항별로 분류하세요. 예를 들어 범용 템플릿: `다음 {{프로그래밍 언어}} 코드를 Code Review해 주세요. {{관심 사항}}에 중점을 두세요:\n\n\`\`\`{{language}}\n{{code}}\n\`\`\``. 관심 사항 변수에는 '보안', '성능', '가독성', '에러 처리' 등을 입력할 수 있습니다.

### Q13: 프로젝트마다 기술 스택이 달라서 프롬프트도 다른데, 어떻게 분리 관리하나요?

**A:** 트리 구조를 사용하여 프로젝트별 폴더로 분류하세요: `개발 / 프로젝트A-React / 리뷰`, `개발 / 프로젝트B-Python / 디버깅`. 각 프로젝트마다 자체 프롬프트 모음이 있어 서로 간섭하지 않습니다. 루트 레벨에 범용 프롬프트(예: Git Commit Message 생성기)를 두어 모든 프로젝트에서 공유할 수도 있습니다.

### Q14: AI로 테스트 케이스를 생성하고 싶은데, 매번 함수를 수동으로 설명하기가 번거롭습니다?

**A:** 테스트 생성 템플릿을 만드세요: `다음 {{프로그래밍 언어}} 함수에 대한 단위 테스트를 생성해 주세요. {{테스트 프레임워크}}를 사용하여, 정상 경로, 경계 조건, 예외 시나리오를 커버해 주세요:\n\n{{함수 코드}}`. 브라우저 확장 프로그램을 활용하면, ChatGPT 대화에서 원클릭으로 이 템플릿을 주입할 수 있습니다.

### Q15: AI에게 에러 메시지 분석을 자주 요청하는데, 빠른 방법이 있나요?

**A:** 디버그 템플릿을 저장하세요: `{{프로젝트명}} 실행 중 다음 에러가 발생했습니다. 기술 스택은 {{기술 스택}}입니다. 원인을 분석하고 해결 방안을 제시해 주세요:\n\n{{에러 메시지}}`. 에러 발생 시 브라우저 확장 프로그램으로 AI 채팅 창에 원클릭 삽입하고, 에러 메시지를 입력하면 바로 전송할 수 있습니다.

### Q16: AI에게 기술 문서(README, API 문서 등) 작성을 요청하고 싶은데, 어떻게 템플릿을 만드나요?

**A:** 문서 유형별로 다른 템플릿을 만드세요. 예를 들어 README 템플릿: `{{프로젝트명}}의 README.md를 생성해 주세요. 프로젝트 소개, 설치 절차, 사용 예시, API 설명, 기여 가이드를 포함해 주세요. 기술 스택: {{기술 스택}}, 프로젝트 설명: {{간략 설명}}`. API 문서 템플릿은 `{{인터페이스 정의}}` 변수를 받을 수 있습니다.

### Q17: 여러 AI 도구를 오가며 사용하는데(ChatGPT, Claude, Gemini), 같은 프롬프트를 여러 번 복사해야 하나요?

**A:** 이것이 바로 **브라우저 확장 프로그램**이 해결하는 문제입니다. PromptTree 브라우저 확장 프로그램을 설치하면, ChatGPT, Claude, Gemini, Poe 어느 대화 페이지에서든 사이드바를 열어 프롬프트를 검색하거나 탐색하고, 원클릭으로 입력란에 주입할 수 있습니다. 수동으로 복사 붙여넣기할 필요가 없습니다.

## 4. 팀 협업 시나리오

### Q18: 저희 팀이 고객 응대 AI 프롬프트를 통일하고 싶은데, 어떻게 하나요?

**A:** 한 사람이 표준 프롬프트 라이브러리를 만들어 관리한 뒤, PromptTree의 **공개 공유** 기능을 통해 공유 링크를 생성하여 팀원에게 보내면 됩니다. 링크로 개별 프롬프트를 공유할 수도 있고, 전체 폴더를 공유할 수도 있습니다. 수신자는 링크를 열면 바로 확인하고 복사할 수 있으며, 가입이 필요 없습니다.

### Q19: 공유한 프롬프트를 여전히 제어할 수 있나요?

**A:** 네. 언제든지 공유 링크를 **철회**할 수 있으며, 철회 후에는 더 이상 해당 링크로 접근할 수 없습니다. 또한 공유 링크의 **조회 통계**도 확인할 수 있습니다 — 몇 명이 열어보았는지, 몇 번 접근되었는지 파악할 수 있습니다.

### Q20: 신규 입사자가 팀의 프롬프트 사용법을 빠르게 익히게 하려면 어떻게 하나요?

**A:** 팀 프롬프트를 '신입 가이드' 폴더로 정리하여, 각 업무 시나리오의 표준 템플릿을 포함시키세요. 공유 링크를 통해 신입에게 전달하면, 프롬프트 내용뿐만 아니라 폴더 구조와 변수 설계도 볼 수 있습니다. 변수명 자체가 사용 설명서가 됩니다 — `{{고객 업종}}`, `{{불만 유형}}`은 보는 즉시 이해할 수 있습니다.

### Q21: 외부 파트너와 일부 프롬프트를 공유해야 하지만, 내부의 모든 내용은 노출하고 싶지 않습니다?

**A:** 특정 폴더나 개별 프롬프트만 공유할 수 있으며, 전체 라이브러리를 공유할 필요는 없습니다. PromptTree의 공유는 노드 수준까지 세밀하게 제어됩니다 — 공유하기로 선택한 콘텐츠만 링크를 통해 노출되고, 나머지 콘텐츠는 완전히 비공개입니다.

### Q22: 팀에서 프로그램으로 프롬프트를 자동 호출하고 싶은데, 어떻게 구현하나요?

**A:** **API 키** 기능을 사용하세요. PromptTree에서 API 키를 생성한 후, 프로그램에서 HTTP 요청으로 프롬프트 데이터에 접근할 수 있습니다. `x-api-key`와 `Bearer` 두 가지 인증 방식을 지원합니다. 자동화 워크플로, CI/CD 파이프라인, 또는 내부 도구에 프롬프트를 연동하기에 적합합니다.

## 5. 멀티 디바이스 및 동기화 시나리오

### Q23: 회사 컴퓨터와 집 컴퓨터 모두에서 사용해야 하는데, 데이터를 어떻게 동기화하나요?

**A:** 같은 계정으로 로그인하면 됩니다. PromptTree는 Google, GitHub, 이메일 Magic Link 세 가지 로그인 방식을 지원합니다. 로그인 후 어느 디바이스에서든 수정하면 **증분 동기화**를 통해 자동으로 클라우드에 동기화됩니다. 다른 디바이스를 열면 자동으로 최신 데이터를 가져옵니다.

### Q24: 출퇴근길에 스마트폰으로 프롬프트를 확인하고 편집할 수 있나요?

**A:** 네. PromptTree는 iOS 및 Android 모바일 앱을 제공하며, 로컬 SQLite 저장소를 사용하여 오프라인 조회 및 편집을 지원합니다. 네트워크에 연결되면 자동으로 데이터가 동기화됩니다. 모바일 버전은 단계별 드릴다운 내비게이션을 채택하여, 작은 화면에서 깊은 구조를 탐색하기에 적합합니다.

### Q25: 비행기에서 네트워크가 없어도 사용할 수 있나요?

**A:** 완전히 가능합니다. PromptTree의 핵심 설계가 바로 **오프라인 우선**입니다 — 모든 데이터가 먼저 로컬 저장소에 기록되고, 클라우드 동기화는 부가적입니다. 완전히 오프라인 상태에서도 프롬프트를 탐색, 생성, 편집, 복사할 수 있습니다. 네트워크가 복구되면 시스템이 오프라인 기간의 모든 수정 사항을 자동으로 동기화합니다.

### Q26: 두 디바이스가 오프라인 상태에서 같은 프롬프트를 수정하면, 충돌이 발생하나요?

**A:** 시스템은 **Last Write Wins**(마지막 수정 시간 기준) 충돌 전략을 채택합니다. 두 디바이스가 동기화할 때, `updatedAt` 타임스탬프가 더 최신인 쪽의 수정이 유지됩니다. 이는 개인 도구 시나리오에서 가장 실용적이고 예측 가능한 전략입니다 — 가장 최근에 수정한 버전이 최종 버전입니다.

### Q27: 웹 버전을 데스크톱 앱처럼 사용할 수 있나요?

**A:** 네. PromptTree의 웹 버전은 **PWA(Progressive Web App)**입니다. 브라우저에서 '데스크톱에 추가' 또는 '앱 설치'를 선택하면, 독립 앱처럼 실행됩니다 — 자체 창, 아이콘이 있으며, 오프라인에서도 사용할 수 있습니다.

## 6. 브라우저 확장 프로그램 시나리오

### Q28: 브라우저 확장 프로그램은 어떤 AI 플랫폼을 지원하나요?

**A:** 현재 **ChatGPT, Claude, Gemini, Poe** 네 가지 주요 AI 대화 플랫폼을 지원합니다. 확장 프로그램 설치 후(Chrome, Edge, Brave 지원), 이 웹사이트의 대화 페이지에서 PromptTree 팝업 패널이 자동으로 활성화됩니다.

### Q29: ChatGPT 대화에서 프롬프트를 빠르게 삽입하고 싶은데, 과정이 어떻게 되나요?

**A:** 확장 프로그램 아이콘을 클릭하여 팝업 패널을 열기 → 트리 구조를 탐색하거나 키워드 검색 → 대상 프롬프트 찾기 → '삽입' 버튼 클릭 → 프롬프트 내용이 ChatGPT 입력란에 자동으로 입력됩니다. 프롬프트에 변수가 있으면, 먼저 변수 채우기 창이 나타나고 작성 후 주입됩니다. 전체 과정에서 현재 페이지를 벗어나지 않습니다.

### Q30: Claude에서 제 프롬프트를 검색할 수 있나요?

**A:** 네. 확장 프로그램 팝업 내에 검색 기능이 있어, 키워드를 입력하면 모든 프롬프트에서 실시간으로 검색됩니다. 검색 결과에 일치하는 내용이 하이라이트되며, 클릭하면 원클릭으로 Claude 입력란에 주입됩니다.

### Q31: 확장 프로그램의 데이터와 웹 버전이 동기화되나요?

**A:** 네. 같은 계정으로 로그인하면 확장 프로그램은 백그라운드에서 주기적으로 동기화됩니다(5분마다). 웹 버전에서 만든 프롬프트를 몇 분 후 확장 프로그램에서 확인하고 사용할 수 있습니다. 확장 프로그램에서 편집한 내용도 역시 동기화됩니다.

### Q32: Gemini에서 다양한 프롬프트를 연속으로 사용하여 멀티턴 대화를 하고 싶은데, 편리한가요?

**A:** 매우 편리합니다. 확장 프로그램 팝업은 계속 열린 상태를 유지하므로, 연속으로 다른 프롬프트를 선택하여 주입할 수 있습니다. 예를 들어 먼저 '요구사항 분석' 프롬프트를 주입하고, AI가 답변한 후 '솔루션 설계' 프롬프트를 주입하면, 구조화된 멀티턴 워크플로가 형성됩니다.

### Q33: 같은 프롬프트를 ChatGPT와 Claude 모두에서 사용하고 싶은데, 두 벌을 관리해야 하나요?

**A:** 아닙니다. 프롬프트는 한 벌만 저장하고, 브라우저 확장 프로그램을 통해 **지원하는 모든 플랫폼**에서 원클릭 주입합니다. 확장 프로그램은 각 플랫폼의 입력란 특성(ChatGPT의 textarea, Claude의 ProseMirror 에디터, Gemini의 리치 텍스트 에디터 등)에 맞게 주입 방식을 자동으로 적용합니다.

## 7. 지식 관리 및 시각화

### Q34: 수백 개의 프롬프트가 쌓였는데, 전체적인 뷰를 보고 싶습니다. 어떤 방법이 있나요?

**A:** **마인드맵 뷰**로 전환하세요. 전체 프롬프트 트리를 시각화 그래프로 보여줍니다 — 폴더가 노드이고 프롬프트가 리프입니다. 확대/축소, 이동, 임의의 노드를 클릭하여 상세 보기가 가능하며, 전체 지식 구조의 전모를 직관적으로 파악할 수 있습니다.

### Q35: 마인드맵에서 특정 브랜치의 내용만 보고 싶은데, 포커스할 수 있나요?

**A:** 네. 마인드맵에서 특정 폴더 노드를 클릭하면, 뷰가 해당 폴더로 **드릴다운**되어 해당 브랜치의 하위 노드만 표시됩니다. 이를 통해 시각화 뷰를 벗어나지 않고 특정 주제의 프롬프트를 단계별로 깊이 탐색할 수 있습니다.

### Q36: 폴더를 하나하나 펼치지 않고 모든 프롬프트를 빠르게 훑어보고 싶은데, 플랫한 뷰가 있나요?

**A:** **아웃라인 뷰**로 전환하세요. 모든 프롬프트를 목록 형태로 펼쳐서 보여줍니다(계층 표시는 유지). 검색과 필터를 지원합니다. 프롬프트 수가 많을 때, 트리 구조에서 하나하나 펼치는 것보다 효율적입니다.

### Q37: PromptTree를 AI 지식 베이스로 활용하고 싶은데, 어떤 조언이 있나요?

**A:** 다음과 같은 구조로 정리하는 것을 권장합니다: 첫 번째 레벨은 대분류(업무, 학습, 생활), 두 번째 레벨은 세부 시나리오(글쓰기, 프로그래밍, 번역), 세 번째 레벨은 구체적인 템플릿. 검증된 좋은 프롬프트에 즐겨찾기를 추가하고, 정기적으로 마인드맵으로 전체 구조를 점검하며, 아웃라인 뷰로 빠른 검색을 수행하세요. 이렇게 하면 프롬프트 라이브러리가 지속적으로 축적하고 빠르게 호출할 수 있는 지식 자산이 됩니다.

### Q38: 폴더를 무한히 중첩할 수 있나요?

**A:** 이론적으로 무한 중첩이 가능하며, 레벨 제한은 없습니다. 다만 3~5레벨 이내로 유지하는 것을 권장합니다. 너무 깊으면 탐색 효율이 떨어집니다. 트리 구조의 접기 기억 기능이 마지막으로 펼친 상태를 기억하여, 자주 사용하는 위치로 빠르게 돌아갈 수 있습니다.

## 8. 자동화 및 고급 활용

### Q39: 자체 시스템에서 PromptTree의 데이터를 호출하고 싶은데, API가 있나요?

**A:** 있습니다. **API 키**를 생성한 후, HTTP 인터페이스를 통해 프롬프트 데이터를 읽을 수 있습니다. `x-api-key` Header와 `Bearer Token` 두 가지 인증 방식을 지원합니다. 내부 도구, 자동화 스크립트, 서드파티 시스템에 프롬프트를 통합하기에 적합합니다.

### Q40: 프롬프트 데이터를 정기적으로 자동 백업하고 싶은데, 어떻게 하나요?

**A:** **Agent Skills** 기능을 통해 자동 백업 작업을 구성할 수 있습니다. 시스템이 설정한 규칙에 따라 프롬프트 데이터를 지정된 위치에 자동 백업합니다. 이 기능은 데이터 보안 요구가 높은 사용자나 팀에 특히 적합합니다.

### Q41: Agent Skills가 무엇인가요? 일반 사용과 어떻게 다른가요?

**A:** Agent Skills는 자동화 워크플로를 위해 설계된 고급 기능입니다. '스킬'을 구성할 수 있습니다 — 예를 들어 지정된 데이터 소스에서 자동으로 프롬프트를 가져오거나, 변경 배포 시 그레이스케일 릴리스 및 롤백, 팀의 프롬프트 관리 프로세스 표준화 등. 일반 사용은 수동 작업이고, Skills는 반복 작업을 자동화하는 것입니다.

### Q42: 팀에서 프롬프트의 변경 관리(누가 무엇을 바꿨는지, 롤백이 가능한지)를 구현하고 싶은데, 방법이 있나요?

**A:** **API 키 + Agent Skills**를 결합하면, 프롬프트 변경 관리 프로세스를 구축할 수 있습니다: API를 통해 현재 버전을 읽고, 변경 이력을 기록하며, 문제 발생 시 이전 버전으로 롤백합니다. Skills는 그레이스케일 릴리스를 지원합니다 — 먼저 일부 사용자에게 적용하고, 문제가 없는 것을 확인한 후 전체에 배포합니다.

### Q43: 저는 기술 리더인데, 좋은 프롬프트를 개인 자산에서 팀 자산으로 전환하고 싶습니다. 어떻게 계획하면 좋을까요?

**A:** 세 단계로 진행하세요: 첫 번째 단계, 팀원 각자 PromptTree에서 개인 프롬프트를 축적합니다; 두 번째 단계, 정기적으로 리뷰하여 우수 프롬프트를 공유 기능으로 '팀 표준 라이브러리' 폴더에 통합합니다; 세 번째 단계, API 키를 통해 표준 라이브러리를 팀 도구 체인에 연동하여, 프롬프트 자산의 체계적 관리를 실현합니다.

## 9. 개인정보 보호 및 보안

### Q44: 제 프롬프트 데이터는 어디에 저장되나요? 안전한가요?

**A:** 데이터는 **먼저 로컬에 저장됩니다**(브라우저 IndexedDB / 모바일 SQLite). 로그인하여 동기화를 활성화하면, 데이터가 HTTPS 암호화를 통해 서버로 전송되어 서버 측 SQLite 데이터베이스에 저장됩니다. 동기화하지 않더라도 로컬 데이터는 완전히 사용 가능합니다.

### Q45: 제 프롬프트 내용을 볼 수 있나요?

**A:** 오프라인 모드(로그인하지 않음)를 사용하시면, 데이터가 완전히 디바이스에 있으므로 저희는 접근할 수 없고 하지도 않습니다. 로그인하여 동기화하면, 서버에 멀티 디바이스 동기화를 위한 데이터가 저장되지만, 저희는 그 콘텐츠를 다른 목적으로 사용하지 않습니다.

### Q46: 더 이상 사용하고 싶지 않으면, 데이터를 삭제할 수 있나요?

**A:** 로컬 데이터는 언제든지 브라우저를 통해 삭제할 수 있습니다. 클라우드 데이터는 소프트 삭제 메커니즘을 통해 처리됩니다 — 삭제된 노드에 `deletedAt` 타임스탬프가 표시되고, 다음 동기화 시 모든 디바이스로 전파됩니다.

| 이런 분이라면 | PromptTree가 도와드리는 것 |
|---------------|---------------------------|
| 소셜 미디어 운영자 | 변수 템플릿으로 다양한 플랫폼의 카피를 대량 생산 |
| 개발자 | 프로젝트와 언어별로 코드 리뷰, 디버깅, 문서 템플릿 정리 |
| 팀 관리자 | 공유와 API로 팀 프롬프트 표준 라이브러리 구축 |
| 프리랜서 | 오프라인 관리, 멀티 디바이스 동기화, 언제 어디서나 호출 |
| AI 헤비 유저 | 브라우저 확장 프로그램 원클릭 주입, 마인드맵 전체 관리 |

**가입 필요 없이 열면 바로 사용할 수 있습니다.** 마음에 드시면 로그인 한 번으로 멀티 디바이스 동기화가 됩니다.
