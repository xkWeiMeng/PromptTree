## 하나의 시나리오

여러분이 번역 업무를 담당하고 있으며, 매일 AI를 사용하여 다양한 언어의 텍스트를 번역해야 한다고 가정해 봅시다. 프롬프트는 대략 이런 모습일 것입니다:

```
다음 한국어 텍스트를 영어로 번역해 주세요. 원문의 어조를 유지하세요. 전문 용어의 정확성에 주의해 주세요.

원문:
(여기에 한국어 내용을 붙여넣기)
```

문제는, 한국어에서 영어로만 번역하는 것이 아니라는 점입니다. 아마 다음과 같은 번역이 필요할 것입니다:
- 한국어 → 영어
- 영어 → 한국어
- 일본어 → 한국어
- 한국어 → 프랑스어

매번 언어 쌍을 수동으로 바꿔야 하므로 번거롭습니다. 매개변수만 다른 비슷한 프롬프트가 10개 있다면, 10개의 버전을 유지 관리해야 합니다.

## 변수 채우기의 해결책

PromptTree에서는 **하나의** 프롬프트 템플릿만 있으면 됩니다:

```
다음 {{원본 언어}} 텍스트를 {{대상 언어}}로 번역해 주세요. 원문의 어조를 유지하세요.
{{분야}} 분야 전문 용어의 정확성에 주의해 주세요.

원문:
{{번역할 내용}}
```

하나의 템플릿으로 모든 번역 시나리오를 커버할 수 있습니다.

## 사용 흐름

1. 복사 버튼을 클릭합니다
2. PromptTree가 자동으로 4개의 변수를 감지합니다
3. 채우기 창이 나타나며, 각 변수마다 입력란이 있습니다
4. 입력합니다: 원본 언어=한국어, 대상 언어=영어, 분야=의학, 번역할 내용=...
5. '복사'를 클릭하면 — 변수가 대체되어 완성된 프롬프트가 클립보드에 복사됩니다

전체 과정이 10초도 걸리지 않습니다.

## 더 많은 활용 시나리오

### 코드 리뷰

```
다음 {{프로그래밍 언어}} 코드를 리뷰해 주세요. {{관심 사항}}에 중점을 두세요:
{{코드}}
```

### 카피라이팅 리라이트

```
다음 카피를 {{스타일}} 스타일로 리라이트해 주세요. 타겟 대상은 {{타겟 대상}}이며, {{글자 수}}자 이내로 작성해 주세요:
{{원문}}
```

### 회의록

```
다음 회의 녹음을 바탕으로 구조화된 회의록을 정리해 주세요.
회의 주제: {{회의 주제}}
참석자: {{참석자}}
녹음 내용: {{녹음 텍스트}}
```

## 설계 철학

변수 채우기의 설계는 하나의 원칙을 따릅니다: **최소 저항의 재사용.**

프로그래밍을 배울 필요도, 템플릿 엔진을 이해할 필요도 없습니다. 이중 중괄호 안에 이름을 넣으면 그것이 바로 변수입니다. 복사를 누르면 채우기 창이 나타나고, 작성하면 결과를 얻을 수 있습니다.

이를 통해 프롬프트가 '일회성 텍스트'에서 '재사용 가능한 템플릿'으로 변하고, 여러분의 프롬프트 라이브러리는 진정한 복리 효과를 발휘하기 시작합니다.
