## 你的 Prompt 在哪里？

问一个每天使用 ChatGPT 的人这个问题，你大概率会得到一个尴尬的笑容。

AI 工具的使用频率越高，Prompt 管理的混乱就越严重。这不是用户的问题，而是整个工具链的缺失。

## 五大痛点

### 1. 散落各处

调研结果显示，大多数用户的 Prompt 散落在至少 3 个不同的地方——笔记应用、浏览器书签、聊天记录、甚至微信「文件传输助手」。

没有一个「Prompt 该放在这里」的共识，因为没有一个为此而生的工具。

### 2. 找不到

「我记得之前写过一个特别好用的翻译 Prompt，但是找不到了。」

这是最常见的抱怨。当你的 Prompt 分散在各处且没有分类时，回忆和搜索都变得困难。

### 3. 无法复用

好的 Prompt 往往是模板化的。比如翻译，核心结构固定，只需要替换源语言、目标语言和内容。但在大多数笔记工具中，你每次都需要手动修改。

### 4. 多端不通

在电脑上整理的 Prompt，手机上用不了。在 Chrome 书签里收藏的，换个浏览器就没了。

### 5. 依赖网络

很多管理工具依赖云端，地铁上、飞机上想查一个 Prompt？对不起，没网用不了。

## 解决思路

针对这些痛点，PromptTree 的解法是：

| 痛点 | 解法 |
|------|------|
| 散落各处 | 一个统一的树形 Prompt 库 |
| 找不到 | 分类 + 搜索 + 收藏 |
| 无法复用 | `{{variable}}` 变量填充 |
| 多端不通 | Web + App + 插件 + 云端同步 |
| 依赖网络 | 离线优先架构 |

每一个设计决策都源自真实的使用痛点。我们相信，好的工具应该解决真实问题，而不是创造新的复杂性。

## 从痛点到产品

了解这些痛点只是第一步。真正的挑战在于：如何在一个简洁的产品中同时解决所有这些问题，而不让产品变得复杂。

PromptTree 的答案是：回归最基础的交互——文件管理器。每个人都知道怎么使用文件夹和文件，不需要学习新的概念。

在此基础上，加入 Prompt 场景特有的能力（变量填充、一键复制、浏览器插件填入），让工具既简单又强大。
