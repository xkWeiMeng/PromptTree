## 一、入门与基础操作

### Q1: 我只是偶尔用 ChatGPT，需要专门的工具管理 Prompt 吗？

**A:** 如果你已经积累了超过 10 条常用 Prompt，就值得试试。PromptTree 不需要注册，打开即用——你的 Prompt 全部存在本地浏览器中。把常用的翻译、写作、总结类 Prompt 存下来，下次直接一键复制，省去每次重新回忆和输入的时间。

### Q2: 我不想注册账号，能用吗？

**A:** 完全可以。PromptTree 采用**离线优先**架构，所有数据默认存储在你的浏览器本地（IndexedDB）。无需注册、无需登录，打开网页就能创建文件夹、编写 Prompt、使用变量填充。只有当你需要多设备同步时，才需要登录。

### Q3: 我的 Prompt 越来越多，怎么组织才不会乱？

**A:** 用**树形文件夹**结构来管理。就像你在电脑上用文件夹管理文件一样——你可以创建多层嵌套的文件夹，比如「工作 / 周报 / 英文版」「个人 / 翻译 / 中译英」。支持拖拽排序、折叠展开、重命名，交互方式和 macOS Finder 一致，上手零成本。

### Q4: 我有几条 Prompt 用得特别频繁，每次都要翻好久才找到，怎么办？

**A:** 给它们加星标**收藏**。收藏后的 Prompt 会出现在侧边栏的「收藏」区域，一步到达。另外你也可以用 `⌘+K`（Mac）或 `Ctrl+K`（Windows）唤起全局搜索，输入关键词秒定位。

### Q5: 我想把聊天记录中好用的回复也存下来，可以吗？

**A:** 当然。在 PromptTree 里创建一个新 Prompt，把回复内容粘贴进去就行。你可以建一个「AI 优质回复」文件夹，把不同主题的好回复分类存放，逐步构建你自己的 AI 知识库。

## 二、内容创作者场景

### Q6: 我是自媒体运营，每天要写不同平台的文案，怎么提效？

**A:** 创建一个「文案模板」文件夹，按平台分子文件夹（小红书、公众号、抖音等）。每个 Prompt 用**变量填充**功能：比如写一条 `请为{{产品名称}}撰写一篇{{平台}}风格的推广文案，目标受众是{{用户画像}}，核心卖点是{{卖点}}`。每次只需填几个变量，5 秒完成一条新 Prompt。

### Q7: 我经常需要把中文内容翻译成多种语言，能简化这个流程吗？

**A:** 这是变量填充的经典场景。创建一条翻译 Prompt：`请将以下{{源语言}}内容翻译为{{目标语言}}，领域为{{行业}}，风格要求{{风格}}：\n\n{{待翻译内容}}`。不管是中译英、中译日还是中译韩，同一条模板，换个变量值就行。

### Q8: 写长文时我习惯分步骤提问（先大纲、再段落、再润色），怎么管理这些步骤？

**A:** 在一个文件夹下创建多条有序的 Prompt，比如 `01-生成大纲`、`02-扩写段落`、`03-润色优化`、`04-生成标题`。每条 Prompt 内用变量标记动态内容（如 `{{文章主题}}`、`{{目标字数}}`），形成你自己的「长文生产线」。

### Q9: 我做 SEO 内容，需要针对不同关键词批量生成文章，PromptTree 能帮到我吗？

**A:** 可以。创建一条 SEO 文章模板：`请围绕关键词"{{关键词}}"，撰写一篇{{字数}}字的 SEO 友好文章，包含 H2/H3 标题，自然嵌入关键词{{次数}}次`。每次填入不同关键词，一键复制到 AI 工具。配合浏览器插件，甚至不用切换页面。

### Q10: 我需要为同一个产品写不同调性的文案（正式/活泼/专业），每次都要改很多？

**A:** 在变量里加一个 `{{调性}}` 就行。同一个 Prompt 模板，填入「正式商务风」「活泼社交风」「专业技术风」就会得到完全不同的输出。你也可以把不同调性的模板各存一份到同一个文件夹里，方便快速切换。

### Q11: 我的 Prompt 经过多次迭代才变好用的，怎么防止误改？

**A:** PromptTree 里每次保存都会更新版本号（`version` 字段递增）。你可以把已经打磨好的 Prompt 加上收藏标记，另外创建一个「实验区」文件夹专门用来测试新版本。确认效果好再替换正式版。

## 三、开发者场景

### Q12: 我做 Code Review 时经常用 AI 辅助，怎么管理 Review Prompt？

**A:** 创建一个「Code Review」文件夹，按语言或关注点分类。比如一条通用模板：`请对以下{{编程语言}}代码进行 Code Review，重点关注{{关注点}}：\n\n\`\`\`{{language}}\n{{code}}\n\`\`\``。关注点变量可以填「安全性」「性能」「可读性」「错误处理」等。

### Q13: 不同项目的技术栈不同，Prompt 也不同，怎么分开管理？

**A:** 用树形结构按项目分文件夹：`开发 / 项目A-React / Review`、`开发 / 项目B-Python / 调试`。每个项目有自己的 Prompt 集合，互不干扰。你也可以在根层级放通用的 Prompt（如 Git Commit Message 生成器），各项目共享。

### Q14: 我想用 AI 生成测试用例，每次手动描述函数太麻烦了？

**A:** 创建测试生成模板：`为以下{{编程语言}}函数生成单元测试，使用{{测试框架}}，覆盖正常路径、边界条件和异常场景：\n\n{{函数代码}}`。配合浏览器插件，你可以直接在 ChatGPT 对话中一键注入这个模板。

### Q15: 我经常需要 AI 帮我解释报错信息，有快捷方式吗？

**A:** 存一条 Debug 模板：`我在运行{{项目名}}时遇到以下报错，技术栈是{{技术栈}}，请分析原因并给出解决方案：\n\n{{错误信息}}`。遇到报错时直接用浏览器插件在 AI 聊天窗口一键插入，填上报错信息就能发送。

### Q16: 我想让 AI 帮忙写技术文档（README、API 文档等），怎么做模板？

**A:** 按文档类型创建不同模板。例如 README 模板：`为{{项目名}}生成 README.md，包含：项目简介、安装步骤、使用示例、API 说明、贡献指南。技术栈：{{技术栈}}，项目描述：{{简述}}`。API 文档模板可以接收 `{{接口定义}}` 变量。

### Q17: 我在多个 AI 工具之间切换（ChatGPT、Claude、Gemini），同一个 Prompt 要复制多次？

**A:** 这正是**浏览器插件**解决的问题。安装 PromptTree 浏览器插件后，在 ChatGPT、Claude、Gemini、Poe 任意一个的对话页面都可以打开侧边栏，搜索或浏览你的 Prompt，一键注入到输入框，不需要手动复制粘贴。

## 四、团队协作场景

### Q18: 我们团队想统一客服回复的 AI Prompt，怎么做？

**A:** 由一个人创建并维护标准 Prompt 库，然后通过 PromptTree 的**公开分享**功能，生成一个分享链接发给团队成员。链接可以分享单个 Prompt，也可以分享整个文件夹。接收方打开链接即可查看和复制，无需注册。

### Q19: 分享出去的 Prompt 我还能控制吗？

**A:** 可以。你可以随时**撤销**分享链接，撤销后别人无法再通过该链接访问。你还可以查看分享链接的**查看统计**——有多少人打开过、被访问了多少次。

### Q20: 新同事入职，怎么快速让他掌握团队的 Prompt 使用方法？

**A:** 把团队 Prompt 组织成「新人入门」文件夹，包含各业务场景的标准模板。通过分享链接发给新人，他不仅能看到 Prompt 内容，还能看到文件夹结构和变量设计。变量名本身就是使用说明——`{{客户行业}}`、`{{投诉类型}}` 一看就懂。

### Q21: 我们和外部合作伙伴需要共享一些 Prompt，但不想暴露内部全部内容？

**A:** 你可以只分享特定的文件夹或单个 Prompt，而不是整个库。PromptTree 的分享是精确到节点级别的——只有你选择分享的内容才会通过链接暴露，其余内容完全私有。

### Q22: 团队想通过程序自动调用我们的 Prompt，怎么实现？

**A:** 使用 **API Key** 功能。在 PromptTree 中创建 API Key，然后在你的程序中通过 HTTP 请求访问 Prompt 数据。支持 `x-api-key` 和 `Bearer` 两种认证方式。适合将 Prompt 接入自动化工作流、CI/CD 流水线或内部工具。

## 五、多设备与同步场景

### Q23: 我在公司电脑和家里的电脑都要用，数据怎么同步？

**A:** 登录同一个账号即可。PromptTree 支持 Google、GitHub 和邮箱 Magic Link 三种登录方式。登录后，你在任一设备上的修改都会通过**增量同步**自动同步到云端。另一台设备打开时会自动拉取最新数据。

### Q24: 通勤路上想在手机上查看和编辑 Prompt，可以吗？

**A:** 可以。PromptTree 提供 iOS 和 Android 移动端应用，使用本地 SQLite 存储，支持离线查看和编辑。数据会在连上网络后自动同步。手机端采用逐级钻入的导航方式，适合小屏幕浏览深层结构。

### Q25: 坐飞机没有网络，还能用吗？

**A:** 完全可以。PromptTree 的核心设计就是**离线优先**——所有数据首先写入本地存储，云端同步是附加的。哪怕完全断网，你依然可以浏览、创建、编辑、复制 Prompt。等恢复网络后，系统会自动同步你离线期间的所有修改。

### Q26: 如果两台设备离线时都改了同一条 Prompt，会冲突吗？

**A:** 系统采用 **Last Write Wins**（以最后修改时间为准）的冲突策略。当两台设备同步时，`updatedAt` 时间戳更新的那一方的修改会被保留。这是个人工具场景下最实用、最可预测的策略——你最近改的那个版本就是最终版本。

### Q27: 网页版可以像桌面应用一样使用吗？

**A:** 可以。PromptTree 的网页版是 **PWA（渐进式 Web 应用）**，你可以在浏览器中选择「添加到桌面」或「安装应用」，之后就像独立应用一样运行——有自己的窗口、图标，离线也能用。

## 六、浏览器插件场景

### Q28: 浏览器插件支持哪些 AI 平台？

**A:** 目前支持 **ChatGPT、Claude、Gemini、Poe** 四个主流 AI 对话平台。安装插件后（支持 Chrome、Edge、Brave），在这些网站的对话页面会自动激活 PromptTree 的弹出面板。

### Q29: 我在 ChatGPT 对话中，想快速插入一条 Prompt，流程是什么样的？

**A:** 点击插件图标打开弹出面板 → 浏览树形结构或搜索关键词 → 找到目标 Prompt → 点击「插入」按钮 → Prompt 内容自动填入 ChatGPT 的输入框。如果 Prompt 包含变量，会先弹出变量填充框，填完后再注入。全程不离开当前页面。

### Q30: 我在 Claude 里能搜索我的 Prompt 吗？

**A:** 可以。插件弹窗内有搜索功能，输入关键词即可在你的所有 Prompt 中实时搜索。搜索结果会高亮匹配内容，点击即可一键注入到 Claude 的输入框中。

### Q31: 插件里的数据和网页版是同步的吗？

**A:** 是的。插件登录同一个账号后，数据通过后台定期同步（每 5 分钟一次）。你在网页版创建的 Prompt，几分钟后就能在插件里看到并使用。插件内编辑的内容也会同步回去。

### Q32: 我想在 Gemini 里连续用不同 Prompt 进行多轮对话，方便吗？

**A:** 很方便。插件弹窗一直保持打开状态，你可以连续选择不同的 Prompt 注入。比如先注入「需求分析」Prompt，等 AI 回复后，再注入「方案设计」Prompt，形成一个有结构的多轮工作流。

### Q33: 同一个 Prompt 我在 ChatGPT 和 Claude 里都想用，需要维护两份吗？

**A:** 不需要。Prompt 只存一份，通过浏览器插件在**任何支持的平台**上一键注入。插件会根据不同平台的输入框特性（ChatGPT 的 textarea、Claude 的 ProseMirror 编辑器、Gemini 的富文本编辑器等）自动适配注入方式。

## 七、知识管理与可视化

### Q34: 我积累了几百条 Prompt，想看个全局视图，有什么方式？

**A:** 切换到**思维导图视图**。它会把你的整个 Prompt 树以可视化图谱的方式展示出来——文件夹是节点，Prompt 是叶子。你可以缩放、平移、点击任意节点深入查看，直观了解整个知识结构的全貌。

### Q35: 思维导图里我只想看某个分支的内容，能聚焦吗？

**A:** 可以。在思维导图中点击某个文件夹节点，视图会**钻入**到该文件夹，只显示该分支的子节点。这样你可以在不离开可视化视图的情况下，逐层深入浏览特定主题的 Prompt。

### Q36: 我想快速浏览所有 Prompt 而不想一层层展开文件夹，有没有扁平化的视图？

**A:** 切换到**大纲视图**。它以列表的形式把所有 Prompt 平铺展示（同时保留层级标识），支持搜索和过滤。当你的 Prompt 数量很多时，这比在树形结构里逐个展开效率更高。

### Q37: 我想把 PromptTree 当作我的 AI 知识库来用，有什么建议？

**A:** 建议按这样的结构组织：第一层是大领域（工作、学习、生活），第二层是细分场景（写作、编程、翻译），第三层是具体模板。把经过验证的好 Prompt 加上收藏标记，定期用思维导图检视全局结构，用大纲视图做快速检索。这样你的 Prompt 库就是一座可以不断积累、快速调用的知识资产。

### Q38: 文件夹可以无限嵌套吗？

**A:** 理论上可以无限嵌套，没有层级限制。不过建议控制在 3-5 层以内，太深会影响浏览效率。树形结构的折叠记忆功能会记住你上次展开的状态，方便快速回到常用位置。

## 八、自动化与高级用法

### Q39: 我想在自己的系统中调用 PromptTree 的数据，有 API 吗？

**A:** 有。创建 **API Key** 后，你可以通过 HTTP 接口读取你的 Prompt 数据。支持 `x-api-key` Header 和 `Bearer Token` 两种认证方式。适合将 Prompt 集成到内部工具、自动化脚本或第三方系统中。

### Q40: 我想定期自动备份我的 Prompt 数据，怎么做？

**A:** 通过 **Agent Skills** 功能，可以配置自动备份任务。系统会按你设定的规则自动将 Prompt 数据备份到指定位置。这个功能特别适合对数据安全要求较高的用户或团队。

### Q41: 什么是 Agent Skills？和普通使用有什么区别？

**A:** Agent Skills 是为自动化工作流设计的进阶功能。它允许你配置「技能」——比如自动从指定数据源拉取 Prompt、变更上线时的灰度发布与回滚、标准化团队的 Prompt 管理流程。普通使用是手动操作，Skills 是把重复操作自动化。

### Q42: 我们团队想实现 Prompt 的变更管理（谁改了什么、能不能回滚），有办法吗？

**A:** 结合 **API Key + Agent Skills**，你可以构建一套 Prompt 的变更管理流程：通过 API 读取当前版本、记录变更历史、在出问题时回滚到上一个版本。Skills 支持灰度发布——先对部分用户生效，确认无问题再全量推广。

### Q43: 我是技术负责人，想把好的 Prompt 从个人资产变成团队资产，怎么规划？

**A:** 分三步走：第一步，团队成员各自在 PromptTree 中积累个人 Prompt；第二步，定期评审，将优质 Prompt 通过分享功能汇聚到「团队标准库」文件夹；第三步，通过 API Key 将标准库接入团队工具链，实现 Prompt 资产的制度化管理。

## 九、隐私与安全

### Q44: 我的 Prompt 数据存在哪里？安全吗？

**A:** 你的数据**首先存储在本地**（浏览器 IndexedDB / 移动端 SQLite）。如果你选择登录并开启同步，数据会通过 HTTPS 加密传输到服务端，存储在服务端 SQLite 数据库中。即使不同步，本地数据完全可用。

### Q45: 你们能看到我的 Prompt 内容吗？

**A:** 如果你使用离线模式（不登录），数据完全在你的设备上，我们无法也不会访问。如果你登录同步，服务端会存储你的数据用于多设备同步，但我们不会将你的内容用于任何其他目的。

### Q46: 如果我不想继续使用，数据能删除吗？

**A:** 本地数据你可以随时通过浏览器清除。云端数据可以通过软删除机制处理——删除的节点会标记 `deletedAt` 时间戳，在下一次同步时传播到所有设备。
