## 一个场景

假设你是一个翻译工作者，每天需要使用 AI 翻译不同语言的文本。你的 Prompt 大概长这样：

```
请将以下中文文本翻译成英文，保持原文语气。注意专业术语的准确性。

原文：
（这里粘贴中文内容）
```

问题是，你不是只翻中译英。你可能需要：
- 中文 → 英文
- 英文 → 中文
- 日文 → 中文
- 中文 → 法语

每次都要手动改语言对，很麻烦。如果有 10 个类似但参数不同的 Prompt，你需要维护 10 个版本。

## 变量填充的解法

在 PromptTree 中，你只需要**一个** Prompt 模板：

```
请将以下 {{源语言}} 文本翻译成 {{目标语言}}，保持原文语气。
注意 {{领域}} 领域专业术语的准确性。

原文：
{{待翻译内容}}
```

一个模板覆盖所有翻译场景。

## 使用流程

1. 点击复制按钮
2. PromptTree 自动检测到 4 个变量
3. 弹出填充窗口，每个变量一个输入框
4. 填入：源语言=中文，目标语言=英文，领域=医学，待翻译内容=...
5. 点击「复制」——变量被替换，完整 Prompt 复制到剪贴板

全程不到 10 秒。

## 更多使用场景

### 代码审查

```
审查以下 {{编程语言}} 代码，关注 {{关注点}}：
{{代码}}
```

### 文案改写

```
将以下文案改写为 {{风格}} 风格，目标受众是 {{目标受众}}，字数控制在 {{字数}} 字以内：
{{原文}}
```

### 会议纪要

```
请根据以下会议录音整理出结构化的会议纪要。
会议主题：{{会议主题}}
参会人员：{{参会人员}}
录音内容：{{录音文字}}
```

## 设计哲学

变量填充的设计遵循一个原则：**最小阻力复用。**

不需要学编程，不需要理解模板引擎。两个花括号包一个名字，就是变量。点复制就弹窗填写，填完就得到结果。

这让 Prompt 从「一次性文本」变成了「可复用模板」，你的 Prompt 库从此真正产生复利效应。
