## 问题的起点

如果你是一个频繁使用 ChatGPT、Claude 等 AI 工具的人，你一定遇到过这样的困境：

你精心打磨了一个效果很好的 Prompt，用完之后……就再也找不到了。

它可能散落在：
- 一个 Notion 页面的某个角落
- 一个叫做「乱七八糟」的文本文件里
- 浏览器的某个书签里
- 或者干脆，在你的记忆中渐渐模糊

## Prompt 的独特性

Prompt 不是普通的文本。它有几个特殊之处：

**数量庞大且持续增长。** 每天和 AI 对话时，你都可能发现新的好用 Prompt。几个月下来，积累几十上百条是很正常的事。

**需要分类。** 工作用的、写作用的、编程用的、翻译用的……不同场景的 Prompt 需要清晰的分类。

**需要模板化。** 很多 Prompt 的结构是固定的，只是某些参数不同。比如翻译 Prompt，只需要替换「源语言」「目标语言」「翻译内容」就能复用。

**需要随时取用。** 当你在 ChatGPT 页面聊天时，你需要快速找到之前存好的 Prompt，不想打开另一个 App 来回切换。

## 现有工具的不足

我们试过很多工具：

- **笔记应用**（Notion, Bear）：功能太重，管理 Prompt 这种短文本用大炮打蚊子
- **Chrome 书签**：没有结构，搜索困难，更无法填充变量
- **纯文本文件**：最原始但最无力的方式
- **其他 Prompt 管理工具**：要么功能匮乏，要么设计粗糙，要么强制在线

没有一个工具能同时满足「树形分类 + 变量填充 + 离线可用 + 多端同步」这些需求。

## PromptTree 的诞生

于是我们决定自己做一个。

核心设计理念很简单：**像管理文件一样管理 Prompt。**

文件管理器是每个人都熟悉的交互模式——文件夹嵌套、拖拽排序、展开折叠。我们把这套交互搬到了 Prompt 管理上：

- 🌳 **树形结构**：用文件夹组织，用层级表达归属
- ✏️ **变量填充**：`{{variable}}` 语法让模板真正可复用
- 📱 **多端同步**：Web + App + 浏览器插件，随时随地
- 🔒 **离线优先**：数据本地存储，不依赖网络

## 取名 PromptTree

Prompt + Tree，简单直接。

一棵树，从根到叶，层次分明。就像你的 Prompt 库应该有的样子。

我们希望 PromptTree 不仅是一个存储工具，更是你的 AI 灵感图书馆——让你积累的每一条 Prompt 都不会被遗忘，在需要时随手可得。
