## 你的 Prompt 在哪裡？

問一個每天使用 ChatGPT 的人這個問題，你大概率會得到一個尷尬的笑容。

AI 工具的使用頻率越高，Prompt 管理的混亂就越嚴重。這不是使用者的問題，而是整個工具鏈的缺失。

## 五大痛點

### 1. 散落各處

調研結果顯示，大多數使用者的 Prompt 散落在至少 3 個不同的地方——筆記應用、瀏覽器書籤、聊天記錄、甚至 LINE「Keep 記事」。

沒有一個「Prompt 該放在這裡」的共識，因為沒有一個為此而生的工具。

### 2. 找不到

「我記得之前寫過一個特別好用的翻譯 Prompt，但是找不到了。」

這是最常見的抱怨。當你的 Prompt 分散在各處且沒有分類時，回憶和搜尋都變得困難。

### 3. 無法複用

好的 Prompt 往往是範本化的。比如翻譯，核心結構固定，只需要替換源語言、目標語言和內容。但在大多數筆記工具中，你每次都需要手動修改。

### 4. 多端不通

在電腦上整理的 Prompt，手機上用不了。在 Chrome 書籤裡收藏的，換個瀏覽器就沒了。

### 5. 依賴網路

很多管理工具依賴雲端，捷運上、飛機上想查一個 Prompt？對不起，沒網用不了。

## 解決思路

針對這些痛點，PromptTree 的解法是：

| 痛點 | 解法 |
|------|------|
| 散落各處 | 一個統一的樹形 Prompt 庫 |
| 找不到 | 分類 + 搜尋 + 收藏 |
| 無法複用 | `{{variable}}` 變數填充 |
| 多端不通 | Web + App + 擴充功能 + 雲端同步 |
| 依賴網路 | 離線優先架構 |

每一個設計決策都源自真實的使用痛點。我們相信，好的工具應該解決真實問題，而不是製造新的複雜性。

## 從痛點到產品

了解這些痛點只是第一步。真正的挑戰在於：如何在一個簡潔的產品中同時解決所有這些問題，而不讓產品變得複雜。

PromptTree 的答案是：回歸最基礎的互動——檔案管理器。每個人都知道怎麼使用資料夾和檔案，不需要學習新的概念。

在此基礎上，加入 Prompt 場景特有的能力（變數填充、一鍵複製、瀏覽器擴充功能填入），讓工具既簡單又強大。
