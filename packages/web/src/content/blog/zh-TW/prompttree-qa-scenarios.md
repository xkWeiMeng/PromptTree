我們經常收到使用者的問題：「PromptTree 到底適合我嗎？」「我能用它做什麼？」

與其泛泛介紹功能，不如用真實場景來回答。這篇文章整理了 **40+ 條場景問答**，涵蓋內容創作、開發、團隊協作、知識管理等多個方向。無論你是剛開始用 AI 的新手，還是日均消耗上百條 Prompt 的重度使用者，都能找到你的使用場景。

## 一、入門與基礎操作

### Q1: 我只是偶爾用 ChatGPT，需要專門的工具管理 Prompt 嗎？

**A:** 如果你已經累積了超過 10 條常用 Prompt，就值得試試。PromptTree 不需要註冊，打開即用——你的 Prompt 全部存在本地瀏覽器中。把常用的翻譯、寫作、摘要類 Prompt 存下來，下次直接一鍵複製，省去每次重新回憶和輸入的時間。

### Q2: 我不想註冊帳號，能用嗎？

**A:** 完全可以。PromptTree 採用**離線優先**架構，所有資料預設儲存在你的瀏覽器本地（IndexedDB）。無需註冊、無需登入，打開網頁就能建立資料夾、編寫 Prompt、使用變數填充。只有當你需要多裝置同步時，才需要登入。

### Q3: 我的 Prompt 越來越多，怎麼組織才不會亂？

**A:** 用**樹形資料夾**結構來管理。就像你在電腦上用資料夾管理檔案一樣——你可以建立多層巢狀的資料夾，比如「工作 / 週報 / 英文版」「個人 / 翻譯 / 中譯英」。支援拖曳排序、摺疊展開、重新命名，互動方式和 macOS Finder 一致，上手零成本。

### Q4: 我有幾條 Prompt 用得特別頻繁，每次都要翻好久才找到，怎麼辦？

**A:** 給它們加星標**收藏**。收藏後的 Prompt 會出現在側邊欄的「收藏」區域，一步到達。另外你也可以用 `⌘+K`（Mac）或 `Ctrl+K`（Windows）喚起全域搜尋，輸入關鍵字秒定位。

### Q5: 我想把聊天記錄中好用的回覆也存下來，可以嗎？

**A:** 當然。在 PromptTree 裡建立一個新 Prompt，把回覆內容貼上去就行。你可以建一個「AI 優質回覆」資料夾，把不同主題的好回覆分類存放，逐步建構你自己的 AI 知識庫。

## 二、內容創作者場景

### Q6: 我是自媒體經營者，每天要寫不同平台的文案，怎麼提效？

**A:** 建立一個「文案範本」資料夾，按平台分子資料夾（小紅書、公眾號、TikTok 等）。每個 Prompt 用**變數填充**功能：比如寫一條 `請為{{產品名稱}}撰寫一篇{{平台}}風格的推廣文案，目標受眾是{{使用者輪廓}}，核心賣點是{{賣點}}`。每次只需填幾個變數，5 秒完成一條新 Prompt。

### Q7: 我經常需要把中文內容翻譯成多種語言，能簡化這個流程嗎？

**A:** 這是變數填充的經典場景。建立一條翻譯 Prompt：`請將以下{{源語言}}內容翻譯為{{目標語言}}，領域為{{產業}}，風格要求{{風格}}：\n\n{{待翻譯內容}}`。不管是中譯英、中譯日還是中譯韓，同一條範本，換個變數值就行。

### Q8: 寫長文時我習慣分步驟提問（先大綱、再段落、再潤飾），怎麼管理這些步驟？

**A:** 在一個資料夾下建立多條有序的 Prompt，比如 `01-產生大綱`、`02-擴寫段落`、`03-潤飾優化`、`04-產生標題`。每條 Prompt 內用變數標記動態內容（如 `{{文章主題}}`、`{{目標字數}}`），形成你自己的「長文生產線」。

### Q9: 我做 SEO 內容，需要針對不同關鍵字批量產生文章，PromptTree 能幫到我嗎？

**A:** 可以。建立一條 SEO 文章範本：`請圍繞關鍵字「{{關鍵字}}」，撰寫一篇{{字數}}字的 SEO 友善文章，包含 H2/H3 標題，自然嵌入關鍵字{{次數}}次`。每次填入不同關鍵字，一鍵複製到 AI 工具。搭配瀏覽器擴充功能，甚至不用切換頁面。

### Q10: 我需要為同一個產品寫不同調性的文案（正式/活潑/專業），每次都要改很多？

**A:** 在變數裡加一個 `{{調性}}` 就行。同一個 Prompt 範本，填入「正式商務風」「活潑社群風」「專業技術風」就會得到完全不同的輸出。你也可以把不同調性的範本各存一份到同一個資料夾裡，方便快速切換。

### Q11: 我的 Prompt 經過多次迭代才變好用的，怎麼防止誤改？

**A:** PromptTree 裡每次儲存都會更新版本號（`version` 欄位遞增）。你可以把已經打磨好的 Prompt 加上收藏標記，另外建立一個「實驗區」資料夾專門用來測試新版本。確認效果好再替換正式版。

## 三、開發者場景

### Q12: 我做 Code Review 時經常用 AI 輔助，怎麼管理 Review Prompt？

**A:** 建立一個「Code Review」資料夾，按語言或關注點分類。比如一條通用範本：`請對以下{{程式語言}}程式碼進行 Code Review，重點關注{{關注點}}：\n\n\`\`\`{{language}}\n{{code}}\n\`\`\``。關注點變數可以填「安全性」「效能」「可讀性」「錯誤處理」等。

### Q13: 不同專案的技術堆疊不同，Prompt 也不同，怎麼分開管理？

**A:** 用樹形結構按專案分資料夾：`開發 / 專案A-React / Review`、`開發 / 專案B-Python / 除錯`。每個專案有自己的 Prompt 集合，互不干擾。你也可以在根層級放通用的 Prompt（如 Git Commit Message 產生器），各專案共享。

### Q14: 我想用 AI 產生測試案例，每次手動描述函式太麻煩了？

**A:** 建立測試產生範本：`為以下{{程式語言}}函式產生單元測試，使用{{測試框架}}，涵蓋正常路徑、邊界條件和異常場景：\n\n{{函式程式碼}}`。搭配瀏覽器擴充功能，你可以直接在 ChatGPT 對話中一鍵注入這個範本。

### Q15: 我經常需要 AI 幫我解釋錯誤訊息，有快捷方式嗎？

**A:** 存一條除錯範本：`我在執行{{專案名}}時遇到以下錯誤，技術堆疊是{{技術堆疊}}，請分析原因並給出解決方案：\n\n{{錯誤訊息}}`。遇到錯誤時直接用瀏覽器擴充功能在 AI 聊天視窗一鍵插入，填上錯誤訊息就能送出。

### Q16: 我想讓 AI 幫忙寫技術文件（README、API 文件等），怎麼做範本？

**A:** 按文件類型建立不同範本。例如 README 範本：`為{{專案名}}產生 README.md，包含：專案簡介、安裝步驟、使用範例、API 說明、貢獻指南。技術堆疊：{{技術堆疊}}，專案描述：{{簡述}}`。API 文件範本可以接收 `{{介面定義}}` 變數。

### Q17: 我在多個 AI 工具之間切換（ChatGPT、Claude、Gemini），同一個 Prompt 要複製多次？

**A:** 這正是**瀏覽器擴充功能**解決的問題。安裝 PromptTree 瀏覽器擴充功能後，在 ChatGPT、Claude、Gemini、Poe 任意一個的對話頁面都可以打開側邊欄，搜尋或瀏覽你的 Prompt，一鍵注入到輸入框，不需要手動複製貼上。

## 四、團隊協作場景

### Q18: 我們團隊想統一客服回覆的 AI Prompt，怎麼做？

**A:** 由一個人建立並維護標準 Prompt 庫，然後透過 PromptTree 的**公開分享**功能，產生一個分享連結發給團隊成員。連結可以分享單個 Prompt，也可以分享整個資料夾。接收方打開連結即可查看和複製，無需註冊。

### Q19: 分享出去的 Prompt 我還能控制嗎？

**A:** 可以。你可以隨時**撤銷**分享連結，撤銷後別人無法再透過該連結存取。你還可以查看分享連結的**瀏覽統計**——有多少人打開過、被存取了多少次。

### Q20: 新同事到職，怎麼快速讓他掌握團隊的 Prompt 使用方法？

**A:** 把團隊 Prompt 組織成「新人入門」資料夾，包含各業務場景的標準範本。透過分享連結發給新人，他不僅能看到 Prompt 內容，還能看到資料夾結構和變數設計。變數名本身就是使用說明——`{{客戶產業}}`、`{{客訴類型}}` 一看就懂。

### Q21: 我們和外部合作夥伴需要共享一些 Prompt，但不想暴露內部全部內容？

**A:** 你可以只分享特定的資料夾或單個 Prompt，而不是整個庫。PromptTree 的分享是精確到節點層級的——只有你選擇分享的內容才會透過連結暴露，其餘內容完全私有。

### Q22: 團隊想透過程式自動呼叫我們的 Prompt，怎麼實現？

**A:** 使用 **API Key** 功能。在 PromptTree 中建立 API Key，然後在你的程式中透過 HTTP 請求存取 Prompt 資料。支援 `x-api-key` 和 `Bearer` 兩種認證方式。適合將 Prompt 接入自動化工作流程、CI/CD 流水線或內部工具。

## 五、多裝置與同步場景

### Q23: 我在公司電腦和家裡的電腦都要用，資料怎麼同步？

**A:** 登入同一個帳號即可。PromptTree 支援 Google、GitHub 和信箱 Magic Link 三種登入方式。登入後，你在任一裝置上的修改都會透過**增量同步**自動同步到雲端。另一台裝置打開時會自動拉取最新資料。

### Q24: 通勤路上想在手機上查看和編輯 Prompt，可以嗎？

**A:** 可以。PromptTree 提供 iOS 和 Android 行動端應用程式，使用本地 SQLite 儲存，支援離線查看和編輯。資料會在連上網路後自動同步。手機端採用逐級鑽入的導覽方式，適合小螢幕瀏覽深層結構。

### Q25: 搭飛機沒有網路，還能用嗎？

**A:** 完全可以。PromptTree 的核心設計就是**離線優先**——所有資料首先寫入本地儲存，雲端同步是附加的。哪怕完全斷網，你依然可以瀏覽、建立、編輯、複製 Prompt。等恢復網路後，系統會自動同步你離線期間的所有修改。

### Q26: 如果兩台裝置離線時都改了同一條 Prompt，會衝突嗎？

**A:** 系統採用 **Last Write Wins**（以最後修改時間為準）的衝突策略。當兩台裝置同步時，`updatedAt` 時間戳較新的那一方的修改會被保留。這是個人工具場景下最實用、最可預測的策略——你最近改的那個版本就是最終版本。

### Q27: 網頁版可以像桌面應用程式一樣使用嗎？

**A:** 可以。PromptTree 的網頁版是 **PWA（漸進式 Web 應用程式）**，你可以在瀏覽器中選擇「加到桌面」或「安裝應用程式」，之後就像獨立應用程式一樣運行——有自己的視窗、圖示，離線也能用。

## 六、瀏覽器擴充功能場景

### Q28: 瀏覽器擴充功能支援哪些 AI 平台？

**A:** 目前支援 **ChatGPT、Claude、Gemini、Poe** 四個主流 AI 對話平台。安裝擴充功能後（支援 Chrome、Edge、Brave），在這些網站的對話頁面會自動啟用 PromptTree 的彈出面板。

### Q29: 我在 ChatGPT 對話中，想快速插入一條 Prompt，流程是什麼樣的？

**A:** 點擊擴充功能圖示打開彈出面板 → 瀏覽樹形結構或搜尋關鍵字 → 找到目標 Prompt → 點擊「插入」按鈕 → Prompt 內容自動填入 ChatGPT 的輸入框。如果 Prompt 包含變數，會先彈出變數填充框，填完後再注入。全程不離開目前頁面。

### Q30: 我在 Claude 裡能搜尋我的 Prompt 嗎？

**A:** 可以。擴充功能彈窗內有搜尋功能，輸入關鍵字即可在你的所有 Prompt 中即時搜尋。搜尋結果會醒目標示匹配內容，點擊即可一鍵注入到 Claude 的輸入框中。

### Q31: 擴充功能裡的資料和網頁版是同步的嗎？

**A:** 是的。擴充功能登入同一個帳號後，資料透過背景定期同步（每 5 分鐘一次）。你在網頁版建立的 Prompt，幾分鐘後就能在擴充功能裡看到並使用。擴充功能內編輯的內容也會同步回去。

### Q32: 我想在 Gemini 裡連續用不同 Prompt 進行多輪對話，方便嗎？

**A:** 很方便。擴充功能彈窗一直保持開啟狀態，你可以連續選擇不同的 Prompt 注入。比如先注入「需求分析」Prompt，等 AI 回覆後，再注入「方案設計」Prompt，形成一個有結構的多輪工作流程。

### Q33: 同一個 Prompt 我在 ChatGPT 和 Claude 裡都想用，需要維護兩份嗎？

**A:** 不需要。Prompt 只存一份，透過瀏覽器擴充功能在**任何支援的平台**上一鍵注入。擴充功能會根據不同平台的輸入框特性（ChatGPT 的 textarea、Claude 的 ProseMirror 編輯器、Gemini 的富文字編輯器等）自動適配注入方式。

## 七、知識管理與視覺化

### Q34: 我累積了幾百條 Prompt，想看個全域視圖，有什麼方式？

**A:** 切換到**心智圖視圖**。它會把你的整個 Prompt 樹以視覺化圖譜的方式展示出來——資料夾是節點，Prompt 是葉子。你可以縮放、平移、點擊任意節點深入查看，直觀了解整個知識結構的全貌。

### Q35: 心智圖裡我只想看某個分支的內容，能聚焦嗎？

**A:** 可以。在心智圖中點擊某個資料夾節點，視圖會**鑽入**到該資料夾，只顯示該分支的子節點。這樣你可以在不離開視覺化視圖的情況下，逐層深入瀏覽特定主題的 Prompt。

### Q36: 我想快速瀏覽所有 Prompt 而不想一層層展開資料夾，有沒有扁平化的視圖？

**A:** 切換到**大綱視圖**。它以列表的形式把所有 Prompt 平鋪展示（同時保留層級標識），支援搜尋和篩選。當你的 Prompt 數量很多時，這比在樹形結構裡逐個展開效率更高。

### Q37: 我想把 PromptTree 當作我的 AI 知識庫來用，有什麼建議？

**A:** 建議按這樣的結構組織：第一層是大領域（工作、學習、生活），第二層是細分場景（寫作、程式開發、翻譯），第三層是具體範本。把經過驗證的好 Prompt 加上收藏標記，定期用心智圖檢視全域結構，用大綱視圖做快速檢索。這樣你的 Prompt 庫就是一座可以不斷累積、快速調用的知識資產。

### Q38: 資料夾可以無限巢狀嗎？

**A:** 理論上可以無限巢狀，沒有層級限制。不過建議控制在 3-5 層以內，太深會影響瀏覽效率。樹形結構的摺疊記憶功能會記住你上次展開的狀態，方便快速回到常用位置。

## 八、自動化與進階用法

### Q39: 我想在自己的系統中呼叫 PromptTree 的資料，有 API 嗎？

**A:** 有。建立 **API Key** 後，你可以透過 HTTP 介面讀取你的 Prompt 資料。支援 `x-api-key` Header 和 `Bearer Token` 兩種認證方式。適合將 Prompt 整合到內部工具、自動化腳本或第三方系統中。

### Q40: 我想定期自動備份我的 Prompt 資料，怎麼做？

**A:** 透過 **Agent Skills** 功能，可以設定自動備份任務。系統會按你設定的規則自動將 Prompt 資料備份到指定位置。這個功能特別適合對資料安全要求較高的使用者或團隊。

### Q41: 什麼是 Agent Skills？和一般使用有什麼區別？

**A:** Agent Skills 是為自動化工作流程設計的進階功能。它允許你設定「技能」——比如自動從指定資料源拉取 Prompt、變更上線時的灰度發布與回滾、標準化團隊的 Prompt 管理流程。一般使用是手動操作，Skills 是把重複操作自動化。

### Q42: 我們團隊想實現 Prompt 的變更管理（誰改了什麼、能不能回滾），有辦法嗎？

**A:** 結合 **API Key + Agent Skills**，你可以建構一套 Prompt 的變更管理流程：透過 API 讀取目前版本、記錄變更歷史、在出問題時回滾到上一個版本。Skills 支援灰度發布——先對部分使用者生效，確認無問題再全量推廣。

### Q43: 我是技術負責人，想把好的 Prompt 從個人資產變成團隊資產，怎麼規劃？

**A:** 分三步走：第一步，團隊成員各自在 PromptTree 中累積個人 Prompt；第二步，定期評審，將優質 Prompt 透過分享功能匯聚到「團隊標準庫」資料夾；第三步，透過 API Key 將標準庫接入團隊工具鏈，實現 Prompt 資產的制度化管理。

## 九、隱私與安全

### Q44: 我的 Prompt 資料存在哪裡？安全嗎？

**A:** 你的資料**首先儲存在本地**（瀏覽器 IndexedDB / 行動端 SQLite）。如果你選擇登入並開啟同步，資料會透過 HTTPS 加密傳輸到伺服器端，儲存在伺服器端 SQLite 資料庫中。即使不同步，本地資料完全可用。

### Q45: 你們能看到我的 Prompt 內容嗎？

**A:** 如果你使用離線模式（不登入），資料完全在你的裝置上，我們無法也不會存取。如果你登入同步，伺服器端會儲存你的資料用於多裝置同步，但我們不會將你的內容用於任何其他目的。

### Q46: 如果我不想繼續使用，資料能刪除嗎？

**A:** 本地資料你可以隨時透過瀏覽器清除。雲端資料可以透過軟刪除機制處理——刪除的節點會標記 `deletedAt` 時間戳，在下一次同步時傳播到所有裝置。
