## 一個場景

假設你是一個翻譯工作者，每天需要使用 AI 翻譯不同語言的文字。你的 Prompt 大概長這樣：

```
請將以下中文文字翻譯成英文，保持原文語氣。注意專業術語的準確性。

原文：
（這裡貼上中文內容）
```

問題是，你不是只翻中譯英。你可能需要：
- 中文 → 英文
- 英文 → 中文
- 日文 → 中文
- 中文 → 法語

每次都要手動改語言對，很麻煩。如果有 10 個類似但參數不同的 Prompt，你需要維護 10 個版本。

## 變數填充的解法

在 PromptTree 中，你只需要**一個** Prompt 範本：

```
請將以下 {{源語言}} 文字翻譯成 {{目標語言}}，保持原文語氣。
注意 {{領域}} 領域專業術語的準確性。

原文：
{{待翻譯內容}}
```

一個範本涵蓋所有翻譯場景。

## 使用流程

1. 點擊複製按鈕
2. PromptTree 自動偵測到 4 個變數
3. 彈出填充視窗，每個變數一個輸入框
4. 填入：源語言=中文，目標語言=英文，領域=醫學，待翻譯內容=...
5. 點擊「複製」——變數被替換，完整 Prompt 複製到剪貼簿

全程不到 10 秒。

## 更多使用場景

### 程式碼審查

```
審查以下 {{程式語言}} 程式碼，關注 {{關注點}}：
{{程式碼}}
```

### 文案改寫

```
將以下文案改寫為 {{風格}} 風格，目標受眾是 {{目標受眾}}，字數控制在 {{字數}} 字以內：
{{原文}}
```

### 會議紀要

```
請根據以下會議錄音整理出結構化的會議紀要。
會議主題：{{會議主題}}
與會人員：{{與會人員}}
錄音內容：{{錄音文字}}
```

## 設計哲學

變數填充的設計遵循一個原則：**最小阻力複用。**

不需要學程式設計，不需要理解範本引擎。兩個花括號包一個名字，就是變數。點複製就彈窗填寫，填完就得到結果。

這讓 Prompt 從「一次性文字」變成了「可複用範本」，你的 Prompt 庫從此真正產生複利效應。
