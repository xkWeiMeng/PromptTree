## 問題的起點

如果你是一個頻繁使用 ChatGPT、Claude 等 AI 工具的人，你一定遇過這樣的困境：

你精心打磨了一個效果很好的 Prompt，用完之後……就再也找不到了。

它可能散落在：
- 一個 Notion 頁面的某個角落
- 一個叫做「亂七八糟」的文字檔裡
- 瀏覽器的某個書籤裡
- 或者乾脆，在你的記憶中逐漸模糊

## Prompt 的獨特性

Prompt 不是普通的文字。它有幾個特殊之處：

**數量龐大且持續增長。** 每天和 AI 對話時，你都可能發現新的好用 Prompt。幾個月下來，累積幾十上百條是很正常的事。

**需要分類。** 工作用的、寫作用的、程式開發用的、翻譯用的……不同場景的 Prompt 需要清晰的分類。

**需要範本化。** 很多 Prompt 的結構是固定的，只是某些參數不同。比如翻譯 Prompt，只需要替換「源語言」「目標語言」「翻譯內容」就能複用。

**需要隨時取用。** 當你在 ChatGPT 頁面聊天時，你需要快速找到之前存好的 Prompt，不想打開另一個 App 來回切換。

## 現有工具的不足

我們試過很多工具：

- **筆記應用**（Notion, Bear）：功能太重，管理 Prompt 這種短文字用大砲打蚊子
- **Chrome 書籤**：沒有結構，搜尋困難，更無法填充變數
- **純文字檔**：最原始但最無力的方式
- **其他 Prompt 管理工具**：要麼功能匱乏，要麼設計粗糙，要麼強制線上

沒有一個工具能同時滿足「樹形分類 + 變數填充 + 離線可用 + 多端同步」這些需求。

## PromptTree 的誕生

於是我們決定自己做一個。

核心設計理念很簡單：**像管理檔案一樣管理 Prompt。**

檔案管理器是每個人都熟悉的互動模式——資料夾巢狀、拖曳排序、展開摺疊。我們把這套互動搬到了 Prompt 管理上：

- 🌳 **樹形結構**：用資料夾組織，用層級表達歸屬
- ✏️ **變數填充**：`{{variable}}` 語法讓範本真正可複用
- 📱 **多端同步**：Web + App + 瀏覽器擴充功能，隨時隨地
- 🔒 **離線優先**：資料本地儲存，不依賴網路

## 取名 PromptTree

Prompt + Tree，簡單直接。

一棵樹，從根到葉，層次分明。就像你的 Prompt 庫應該有的樣子。

我們希望 PromptTree 不僅是一個儲存工具，更是你的 AI 靈感圖書館——讓你累積的每一條 Prompt 都不會被遺忘，在需要時隨手可得。
