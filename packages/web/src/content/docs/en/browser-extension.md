## Supported Browsers

- Google Chrome
- Microsoft Edge
- Brave
- Other Chromium-based browsers

## Supported AI Platforms

The PromptTree extension can insert Prompts on the following AI platforms:

- **ChatGPT** (chat.openai.com)
- **Claude** (claude.ai)
- **Google Gemini** (gemini.google.com)
- **Poe** (poe.com)

## Installation

1. Visit the Chrome Web Store (coming soon)
2. Click "Add to Chrome"
3. Pin the extension to the toolbar

## Usage

### Sign In

1. Click the extension icon in the toolbar
2. Choose a sign-in method (Google / GitHub / Email)
3. After signing in, Prompts sync automatically

### Quick Insert

1. Open a supported AI platform (e.g., ChatGPT)
2. Click the PromptTree icon or use the shortcut
3. Select a Prompt from the tree
4. The Prompt is automatically inserted into the input box

### Variable Filling

1. If the selected Prompt contains `{{variables}}`
2. A variable fill dialog will pop up
3. Enter the values for each variable
4. Click Submit — the filled Prompt is inserted into the input box

### Search

- Use the search bar at the top to quickly find Prompts by keyword
- Supports searching by title and content

## Offline Mode

- The extension can also be used in offline mode
- Data is stored in the browser's chrome.storage
- Sign in to enable cloud sync across devices

## Tips

1. **Pin the extension** to the toolbar for quick access
2. **Use folders** to organize your Prompts for easy retrieval
3. **Use variables** for frequently used template Prompts
