## Welcome to PromptTree

PromptTree is a tree-structured AI Prompt management tool that helps you organize and reuse prompts using folders and files.

## Get Started

### 1. Open the Workspace

Open PromptTree in your browser. You can choose:

- **Offline mode**: No sign-up required, data stored locally in your browser — perfect for a quick start
- **Sign in**: Supports Google, GitHub, or email login for cloud sync across devices

### 2. Create a Folder

In the left tree panel, click the **folder icon** in the toolbar to create a new folder. Organize by purpose:

- Work
- Writing
- Programming
- Translation

### 3. Create a Prompt

Click the **file icon** in the toolbar to create a new Prompt. Enter your prompt content in the editor on the right.

### 4. Use Variables

Use `{{variable}}` syntax to define variables in your Prompt:

```
Please translate the following {{language}} text into {{target language}}:

{{content to translate}}
```

When you click the copy button, a variable filling dialog will appear automatically — fill in the values to generate your final prompt.

### 5. One-Click Copy

Every Prompt has a prominent copy button — click to copy the content to your clipboard, then paste directly into ChatGPT or any other AI tool.
