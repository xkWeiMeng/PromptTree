## Global Shortcuts

| Shortcut | Action |
|----------|--------|
| `⌘ + K` | Quick search |
| `⌘ + N` | New Prompt |
| `⌘ + ⇧ + N` | New folder |
| `⌘ + S` | Manual sync |

> On Windows/Linux, replace `⌘` with `Ctrl`.

## Tree Operations

| Shortcut | Action |
|----------|--------|
| `↑` / `↓` | Navigate between nodes |
| `Enter` | Edit/open selected node |
| `Delete` / `Backspace` | Delete selected node |
| `⌘ + C` | Copy node content |
| `Escape` | Cancel / deselect |

## Editor Shortcuts

| Shortcut | Action |
|----------|--------|
| `Tab` | Indent text |
| `⇧ + Tab` | Unindent |
| `⌘ + Z` | Undo |
| `⌘ + ⇧ + Z` | Redo |
| `⌘ + A` | Select all |

## Tips

1. **Quick Search** (`⌘ + K`) is the most frequently used shortcut for quickly locating any Prompt
2. Use `⌘ + N` / `⌘ + ⇧ + N` to quickly create content without leaving the keyboard
3. Arrow keys let you quickly browse the tree structure
