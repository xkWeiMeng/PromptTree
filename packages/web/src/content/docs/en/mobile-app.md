## Supported Platforms

- **iOS** 15.0+
- **Android** 10.0+

## Installation

### iOS
- Download from the App Store (coming soon)

### Android
- Download from Google Play (coming soon)
- Or download the APK directly from the official website

## Core Features

### Tree Management
- View and manage the complete Prompt tree structure
- Create, edit, and delete Prompts and folders
- Drag-and-drop sorting
- Swipe left to reveal quick action buttons

### Variable Filling
- Automatically detects `{{variables}}` in Prompts
- Pop-up dialog for entering variable values
- Preview the filled result before copying

### Quick Copy
- Tap to copy Prompt content
- Fill variables then copy in one step
- Automatic clipboard integration

### Search
- Global full-text search
- Search by title and content
- Real-time search results

## Sync

- Sign in to enable multi-device cloud sync
- Local SQLite storage ensures offline availability
- Auto sync when the network is available

## Interface Features

- Adapts to system light/dark mode
- Native gesture navigation
- Breadcrumb navigation for deep directory structures
- Pull to refresh

## Tips

1. **Swipe left** on items to quickly delete or edit
2. **Long press** a folder to see more options
3. **Pull down** to refresh and sync the latest data
4. Uses a local database — core features work offline
