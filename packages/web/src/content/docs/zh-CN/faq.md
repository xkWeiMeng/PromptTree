## 一般问题

### PromptTree 是免费的吗？

是的，PromptTree 完全免费使用。所有核心功能——树形管理、变量填充、离线使用、多端同步——均免费提供。

### 我的数据安全吗？

PromptTree 采用离线优先架构，你的数据优先存储在本地设备上。云端同步使用 HTTPS 加密传输，服务器数据存储在独立的 SQLite 数据库中。

### 不注册也能使用吗？

可以。PromptTree 支持完全离线模式，无需注册即可使用全部核心功能。数据存储在浏览器的 IndexedDB 中。当你需要多端同步时，再注册登录即可。

## 功能相关

### 支持哪些浏览器？

PromptTree Web App 支持所有现代浏览器：
- Chrome 80+
- Firefox 78+
- Safari 14+
- Edge 80+

### 变量名可以用中文吗？

当然可以。`{{中文变量}}` 完全支持。变量名可以使用任何字符，只要不包含 `{{` 和 `}}` 即可。

### 有没有 Prompt 数量限制？

没有限制。你可以创建任意数量的文件夹和 Prompt。

### 可以导入/导出数据吗？

目前暂不支持导入/导出功能，但已在开发计划中。

## 同步问题

### 数据同步有延迟吗？

修改后会有约 2 秒的防抖延迟，之后自动同步。网络正常情况下，整个同步过程通常在 1-3 秒内完成。

### 多端同时编辑同一个 Prompt 会怎样？

采用 Last Write Wins 策略——以最后一次修改的版本为准。建议避免在多端同时编辑同一条 Prompt。

### 换浏览器后数据还在吗？

如果你已登录账号，数据会同步到云端，换浏览器登录后自动还原。如果使用离线模式（未登录），数据仅存在于当前浏览器中。
