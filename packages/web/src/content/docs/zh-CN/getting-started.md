## 欢迎使用 PromptTree

PromptTree 是一款树形结构的 AI Prompt 管理工具，帮助你用文件夹 + 文件的方式组织和复用 Prompt。

## 服务稳定性与数据安全说明

PromptTree 目前由初创团队持续迭代，服务稳定性仍在不断优化中。受网络波动、基础设施或版本发布影响，云端服务可能出现短时不可用、同步延迟或偶发掉线。

我们会持续投入监控与修复，尽最大努力保障服务可用性并尽快恢复异常。同时，我们会尽力保护你的数据隐私与安全，数据传输过程使用 HTTPS 加密。

我们会尽量降低数据丢失风险，但对于重要内容，仍建议你保留本地副本以获得更稳妥的保障。

如遇使用问题、同步异常或数据相关疑问，请发送邮件至：**hi@prompttree.app**。

## 开始使用

### 1. 访问工作台

打开浏览器访问 PromptTree 工作台。你可以选择：

- **离线模式**：无需注册，数据存储在浏览器本地，适合快速体验
- **登录使用**：支持 Google、GitHub 或邮箱登录，数据云端同步

### 2. 创建文件夹

在左侧树形面板中，点击顶部工具栏的 **文件夹图标** 创建新文件夹。你可以按用途分类：

- 工作
- 写作
- 编程
- 翻译

### 3. 创建 Prompt

点击工具栏的 **文件图标** 创建新的 Prompt。在右侧编辑器中输入你的 Prompt 内容。

### 4. 使用变量

在 Prompt 中使用 `{{variable}}` 语法定义变量：

```
请将以下 {{语言}} 文本翻译成 {{目标语言}}：

{{待翻译内容}}
```

点击复制按钮时，会自动弹出变量填充窗口，填写完成后生成最终 Prompt。

### 5. 一键复制

每个 Prompt 都有醒目的复制按钮，点击即可将内容复制到剪贴板，直接粘贴到 ChatGPT 等 AI 对话工具中使用。
