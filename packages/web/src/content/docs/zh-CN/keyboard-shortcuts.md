## 快捷键列表

PromptTree 提供丰富的键盘快捷键，让你无需离开键盘即可高效操作。

## 全局快捷键

| 快捷键 | 功能 |
|--------|------|
| `⌘ + K` | 打开全局搜索 |
| `⌘ + N` | 新建 Prompt |
| `⌘ + Shift + N` | 新建文件夹 |
| `Escape` | 关闭弹窗 / 取消操作 |

## 树形面板

| 快捷键 | 功能 |
|--------|------|
| `↑ / ↓` | 上下移动选中项 |
| `← / →` | 折叠 / 展开文件夹 |
| `Enter` | 打开选中的 Prompt |
| `Delete` | 删除选中项 |
| `F2` | 重命名选中项 |

## 编辑器

| 快捷键 | 功能 |
|--------|------|
| `⌘ + C` | 复制（编辑器内） |
| `⌘ + Shift + C` | 复制完整 Prompt（触发变量填充） |
| `⌘ + S` | 保存（自动保存，此操作可手动触发同步） |

## 提示

- macOS 使用 `⌘` (Command) 键
- Windows/Linux 使用 `Ctrl` 键
- 快捷键可能与浏览器默认快捷键冲突，PromptTree 会优先处理已注册的快捷键
