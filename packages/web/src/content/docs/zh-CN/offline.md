## 离线优先理念

PromptTree 把本地存储作为数据的第一来源（Single Source of Truth），云端同步是可选的增值功能。这意味着：

- 无网络时，所有功能正常可用
- 数据操作零延迟——直接读写本地数据库
- 网络恢复后自动同步，无需手动操作

## 工作原理

### 本地存储

在 Web 端，数据存储在浏览器的 IndexedDB 中（通过 Dexie.js ORM）。主要存储：

- 所有 Prompt 节点数据（树结构、内容、元信息）
- 用户偏好设置
- 同步元数据（最后同步时间等）

### 离线检测

应用会自动检测网络状态。在离线状态下：

- 顶部状态栏显示"离线"提示
- 所有修改正常保存到本地
- 修改记录标记为"待同步"

### 恢复在线

网络恢复后：

1. 自动触发增量同步
2. 将本地修改上传到云端
3. 拉取其他端的最新修改
4. 状态恢复为"已同步"

## 无需注册即可使用

PromptTree 支持完全离线模式——不注册、不登录也能使用全部核心功能。你的数据安全地存储在浏览器本地。

当你决定需要多端同步时，随时可以注册登录，本地数据会自动同步到云端。

## PWA 支持

PromptTree 是一个 Progressive Web App (PWA)，你可以：

- 将它安装到桌面/主屏幕
- 像原生应用一样打开使用
- 离线场景下依然可以访问
