## 同步机制

PromptTree 采用**离线优先 + 增量同步**的架构：

1. 所有写操作先写入本地数据库
2. 数据修改后标记为"待同步"
3. 防抖 2 秒后自动上传到云端
4. 云端接收后返回增量更新

## 登录同步

要启用云端同步，你需要登录账号。支持三种登录方式：

- **Google 一键登录**：使用 Google 账号快速登录
- **GitHub OAuth**：使用 GitHub 账号登录
- **邮箱魔法链接**：输入邮箱，收到登录链接后点击即可

## 离线模式

未登录时可使用离线模式：

- 所有数据存储在浏览器本地（IndexedDB）
- 功能完全可用，包括创建、编辑、删除、搜索
- 数据仅存在于当前浏览器中
- 后续登录后可同步到云端

## 多端同步

登录同一账号后，数据会在所有端自动同步：

| 平台 | 存储方式 | 同步方式 |
|------|----------|----------|
| Web App | IndexedDB | HTTP 增量同步 |
| iOS / Android | SQLite | HTTP 增量同步 |
| 浏览器插件 | chrome.storage | HTTP 增量同步 |

## 冲突解决

当多端同时编辑同一个 Prompt 时，采用 **Last Write Wins** 策略——以最后一次修改为准（通过 `updatedAt` 时间戳比较）。

## 数据安全

- 传输使用 HTTPS 加密
- 认证使用 JWT Token
- 服务端数据存储在 SQLite 数据库
- 支持离线模式，核心数据不依赖网络
