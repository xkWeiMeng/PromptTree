## 树形结构概览

PromptTree 的核心是树形结构管理。像使用 macOS Finder 或 VS Code 一样，你可以用文件夹嵌套的方式组织 Prompt。

## 节点类型

树中有两种节点：

- **文件夹**：用于分类和组织，可以包含子文件夹和 Prompt
- **Prompt**：存储实际的 Prompt 内容

文件夹和 Prompt 可以在同一层级并列排放。

## 基本操作

### 创建

- 点击工具栏的 **文件夹图标** 创建文件夹
- 点击工具栏的 **文件图标** 创建 Prompt
- 新节点会创建在当前选中文件夹下，或根目录

### 重命名

双击节点标题即可进入编辑模式，修改完成后按 Enter 确认或按 Esc 取消。

### 删除

右键节点选择「删除」，或选中后按 Delete 键。删除操作使用软删除机制，数据不会立即消失。

### 拖拽排序

按住节点拖拽可以：

- 调整同级节点的排列顺序
- 将节点移动到其他文件夹中
- 调整文件夹的嵌套层级

## 无限层级

系统支持无限层级嵌套，不过建议保持在 3-4 层以内以获得最佳使用体验。

推荐的组织方式：

```
📁 工作
  📁 翻译
    📄 中译英通用
    📄 技术文档翻译
  📁 写作
    📄 公众号文章框架
    📄 产品文案润色
📁 编程
  📁 代码审查
  📁 架构设计
📁 学习
  📄 概念解释模板
```

## 折叠与展开

点击文件夹左侧的箭头可以展开或折叠。折叠状态会被记住——即使刷新页面或切换设备，你上次的展开状态都会保留。

## 收藏

给常用的 Prompt 标记星标（收藏），可以在树形面板顶部的「收藏」区域快速访问。
