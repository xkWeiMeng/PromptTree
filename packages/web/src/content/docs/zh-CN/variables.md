## 什么是变量填充？

变量填充是 PromptTree 的核心功能。通过在 Prompt 中使用 `{{变量名}}` 语法，你可以创建可复用的模板。

## 基本用法

在 Prompt 内容中用双花括号包裹变量名：

```
你是一个 {{角色}}，请帮我 {{任务描述}}。

要求：
- 语气：{{语气风格}}
- 字数：{{字数要求}}
```

## 复制时自动填充

当你点击复制按钮时，PromptTree 会自动检测 Prompt 中的变量：

1. 检测到变量后，弹出填充窗口
2. 每个变量显示为一个输入框
3. 填写完成后点击「复制」
4. 变量被替换为实际值，最终 Prompt 复制到剪贴板

## 变量命名规范

- 使用有意义的中文或英文名称
- 变量名不能包含 `{{` 和 `}}` 字符
- 同一个变量名可以在 Prompt 中多次出现，填充时只需输入一次

## 使用示例

### 翻译模板

```
请将以下内容从 {{源语言}} 翻译成 {{目标语言}}。

要求：
- 保持原文的语气和风格
- 专业术语使用 {{领域}} 领域的标准翻译

原文：
{{待翻译内容}}
```

### 代码审查模板

```
请审查以下 {{编程语言}} 代码：

```{{编程语言}}
{{代码内容}}
```

请关注：
1. 代码质量和可读性
2. 潜在的 bug 和安全问题
3. 性能优化建议
```

## 小技巧

- 为频繁使用的变量取统一名称，保持一致性
- 将常用模板放入收藏，加快访问速度
- 配合浏览器插件使用，在 AI 对话页面直接填充变量
